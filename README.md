### 项目简介
本项目针对当前轻食沙拉市场“价格高、制作麻烦、食品安全隐患大、浪费严重”等痛点，设计了一款**全自动营养快餐机**（沙拉售卖机）。通过手机APP/小程序点单、自动化下料、传送、出餐等功能，实现沙拉的快速、个性化、标准化制作，旨在为现代快节奏生活提供健康、便捷、卫生的轻食解决方案。
**项目类型**：仿生 / 智能设备课程设计 + 创新创业项目  
**组员**：仲昱乐（主答辩人）  
**完成日期**：2024-2025

### 核心创新点
- **全自动制作流程**：自动落碗、自动下料、自动传送、自动升降出餐
- **智能化点单**：支持手机APP、小程序提前点单 + 现场触屏点单
- **个性化定制**：多种菜品自由搭配，DIY 沙拉
- **卫生与环保**：减少人工接触、可降解材料、透明可视化制作过程
- **高效节能**：智能冷藏系统 + 自动化优化调度
