### 项目简介
本项目为**光伏货架车**（Photovoltaic Shelf Cart），是一款专为光伏组件（太阳能板）设计的多层滑动式移动货架。采用铝型材框架 + 滑轨系统，可实现多层光伏板快速抽拉、展示、运输及存放，适用于光伏展会、工地临时存放、工厂调试、培训教学等场景。

### 主要特点
- **三层独立滑动层**，每层可承载标准光伏组件
- 带万向脚轮，移动灵活，可锁定
- 铝合金型材框架，轻便且强度高
- 前置透明亚克力/钢化玻璃防护板
- 模块化设计，易拆装、易维护
- 适用于 182/210 大尺寸组件
