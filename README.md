# 2026-012 便携式自动冷萃咖啡机

一套便携式自动冷萃咖啡机原型，采用上下双舱结构和两路独立泵，通过 ESP32-S3 控制咖啡液在上下舱之间循环，并配套 Windows 上位机完成设备联调、手动控制、循环配方与运行记录。

![便携式自动冷萃咖啡机渲染图](./b-Picture/结果图.png)

## 项目概览

项目覆盖从产品结构到软硬件联调的完整原型资料：

- **机械结构**：上下舱体、中部电气仓、泵、电池、管路及整机装配模型。
- **电子硬件**：ESP32-S3 主控、电源与继电器驱动原理图、PCB 和接线资料。
- **嵌入式固件**：基于 Arduino / PlatformIO，实现安全初始化、双泵互锁和串口控制。
- **Windows 上位机**：基于 .NET 8 / WPF，支持模拟与实机模式、手动上液/降液、固定循环、命名配方和历史记录。
- **项目交付**：产品渲染图、汇报文件、用户手册、串口协议及工程设计源文件。

## 工作原理

机器由上舱体、电气仓和下舱体组成。两只泵分别负责两个方向的液体输送：

```text
上液：下舱体 -- GPIO15 / 泵 1 --> 上舱体
降液：上舱体 -- GPIO16 / 泵 2 --> 下舱体
```

上位机按照“上液 -> 停留 -> 降液 -> 停留”的顺序执行可配置循环。当前原型没有液位、温度或压力传感器，运行过程以人工标定的时间为依据，界面中的液位为模拟或估算值。

## 快速开始

### 1. 运行 Windows 上位机

环境要求：Windows 10/11、[.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)。

```powershell
cd "b-Code-上位机程序"
dotnet restore APPShell.sln
dotnet run --project src/App/App.csproj
```

程序可在没有硬件时使用模拟模式。连接 ESP32 时，在右侧控制面板刷新并选择对应串口；默认通讯参数为 `115200 / UTF-8 / JSON Lines`。详细操作见[上位机用户手册](./b-Code-上位机程序/docs/咖啡冷萃机上位机_用户手册.md)。

### 2. 编译并烧录 ESP32 固件

环境要求：VS Code + PlatformIO，目标板为 ESP32-S3 DevKitC-1 兼容板。

```powershell
cd "b-Code-引脚定义和esp32程序/coffee_cold_brew"
pio run
pio run --target upload
pio device monitor --baud 115200
```

固件启动后默认关闭两路继电器，并周期性输出状态快照。实际烧录前请核对 [`platformio.ini`](./b-Code-引脚定义和esp32程序/coffee_cold_brew/platformio.ini) 中的开发板环境以及[引脚定义表](./b-Code-引脚定义和esp32程序/ESP32-S3_引脚定义表.md)。

## 核心控制定义

| 功能 | GPIO | 电平 | 说明 |
| --- | ---: | --- | --- |
| 泵 1 继电器 / 上液 | 15 | HIGH 有效 | 下舱体向上舱体输送 |
| 泵 2 继电器 / 降液 | 16 | HIGH 有效 | 上舱体向下舱体输送 |
| 泵 1 PWM | 1 | 待标定 | 启动时保持 0% |
| 泵 2 PWM | 2 | 待标定 | 启动时保持 0% |
| 模式开关 | 4 | 输入 | 外部 10k 上拉 |
| 电池电压采样 | 5 | ADC | 100k / 47k 分压 |

GPIO15 与 GPIO16 必须保持互斥。方向切换时应先将两路关闭，经过安全死区后再开启目标输出；停机时先将 PWM 降至 0%，再释放继电器。

## 安全与硬件确认

- 上电、复位、断连和程序退出时，两路泵输出都应回到关闭状态；上位机的软件停止不能替代硬件保护。
- 当前原理图中的继电器驱动需在硬件定版前复核 NPN 基极限流电阻及线圈续流二极管的实际网络。
- PWM 频率、极性、最小启动占空比和换向死区需要结合实装泵及驱动电路标定。
- 电池 ADC 换算、板级压降及满电阈值需要通过实测校准，不能直接使用理论值作为保护阈值。
- 未连接到原理图的 GPIO 视为保留资源；新增功能应同步更新原理图、引脚表和固件命名。

## 数据位置

上位机的命名配方和运行历史默认保存在：

```text
%AppData%\ColdBrewMachine\data\brew-m4.json
```

应用最多保留 500 条历史记录，界面显示最近 80 条。重新安装或迁移电脑前，请按需备份该文件。
