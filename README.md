### 项目简介
本项目为**中型AGV小车**（Automated Guided Vehicle），是一款中型智能自主导航搬运机器人。采用差速驱动 + 多雷达感知系统，可实现室内外自主导航、路径规划、物料搬运、自动避障等功能，适用于工厂车间、仓储物流、智能制造等场景。

**主要特点**：平板式承载平台 + 模块化设计，负载能力强，灵活性高。

---

### 主要功能

- **自主导航与路径规划**：支持激光 SLAM / 二维码 / 磁导航等多种导航方式
- **智能避障**：多激光雷达 + 3D 视觉全域感知，实现动态避障
- **物料搬运**：大尺寸平板平台，适合托盘、物料箱、设备运输
- **自动充电**：支持接触式充电刷块或自动充电桩
- **调度系统对接**：可接入上位机调度系统，实现多机协作
- **人机交互**：状态指示灯 + 可选屏幕/语音提示

---

### 设计亮点

- 平板式大承载平台，适合多种物料放置
- 模块化底盘设计，便于后期维护和功能扩展
- 低重心结构 + 悬挂系统，运行稳定
- 自动充电刷块，支持无人值守长时间作业
- 多雷达融合感知，安全可靠

### 技术参数

| 项目              | 参数                          |
|-------------------|-------------------------------|
| 承载重量          | 50kg        |
| 驱动方式          | 差速驱动 / 步科一体式电机     |
| 导航方式          | 激光 SLAM + 多雷达融合        |
| 电池              | 48V 高容量锂电池              |
| 续航              | 长时间作业（待实测）          |
| 充电方式          | 自动充电刷块 + 手动充电口     |
| 感知系统          | 多激光雷达          |
