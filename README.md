### 主要功能
- **智能迎宾与引导**：语音交互 + 自主导航
- **信息查询与交互**：透明大屏显示 + 语音对话（支持数字人）
- **自主导航与避障**：导航雷达 + 多激光雷达全域感知（无盲区）
- **人脸识别**：双目摄像头支持身份验证
- **信息展示与播报**：大屏 + 音响一体化播报
- **自动充电**：充电刷块接触式自动补电，支持无人值守

---

### 设计亮点
- 底盘与悬挂创新结构设计（外部负载不压底盘，稳定性高）
- 四轮结构 + 可调节悬挂，保证全地形稳定不悬空
- 步科一体式 400W 电机
- 自动充电刷块系统
- 车体重心低，抗侧风与加速稳定性优秀
