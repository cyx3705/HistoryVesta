## 3. 外部接口定义

### P1：模式选择接口（Header 3）

| P1 Pin | 网络 | 固件含义 |
|---:|---|---|
| 1 | GND | 选择 LOW 档 |
| 2 | GPIO4 | 开关公共端/模式输入 |
| 3 | 3V3 | 选择 HIGH 档；R1 10k 同时将 GPIO4 上拉至此网络 |

P1 应按 SPDT 选择开关理解：公共端 P1-2 在 GND 与 3V3 之间选择。固件只能把两个电平命名为 `MODE_LOW`、`MODE_HIGH`，在产品功能尚未确定前不要擅自解释为具体工作模式。

### P2：两路电机接口（Header 10）

| P2 Pin | 网络 | 所属通道 | 说明 |
|---:|---|---|---|
| 10 | GND | 电机 1 | 地 |
| 9 | `PW1` | 电机 1 | K1 继电器切换后的 5V 电源 |
| 8 | NC | 电机 1 | 原理图未连接，固件不得使用 |
| 7 | `PWM1` / GPIO1 | 电机 1 | PWM 控制信号 |
| 6 | NC | 电机 1 | 原理图未连接，固件不得使用 |
| 5 | GND | 电机 2 | 地 |
| 4 | `PW2` | 电机 2 | K2 继电器切换后的 5V 电源 |
| 3 | NC | 电机 2 | 原理图未连接，固件不得使用 |
| 2 | `PWM2` / GPIO2 | 电机 2 | PWM 控制信号 |
| 1 | NC | 电机 2 | 原理图未连接，固件不得使用 |

## 4. 电源与保留针脚

| U1 物理 Pin | 名称 | 用途 |
|---:|---|---|
| 1、2 | 3V3 | 3.3V 电源；P1 上拉/高档电平 |
| 21 | 5V | MP1584 降压电路输出给开发板供电 |
| 22、23、24、44 | GND | 公共地 |
| 25、26 | GPIO19、GPIO20 | 原生 USB D-、D+，固件不得占用为普通机器 IO |
| 31 | GPIO0 / BOOT | 启动绑带/下载，保留 |
| 43、42 | GPIO43、GPIO44 | UART0 TX/RX，建议保留给日志与调试 |
| 13、14、30 | GPIO3、GPIO46、GPIO45 | 启动绑带相关针脚，当前未使用，避免新增外设 |

其余未连接 GPIO 视为“保留”，不是“可自由分配”。新增功能必须先更新原理图与本表。

## 5. ADC 换算

原理图分压为：VCC -> R3 100k -> ADC1 -> R4 47k -> GND，ADC1 对地并联 C3 100nF。

```text
ADC 电压 = VCC * 47 / (100 + 47)
VCC      = ADC 电压 * 147 / 47
分压增益 = 3.1276596
```

理论值：VCC=8.4V 时 ADC 约 2.686V；VCC=6.0V 时 ADC 约 1.918V。实际固件应使用实测值校准电阻误差、ADC 参考误差和板级压降。

## 6. 推荐的安全初始化顺序

1. 最早阶段将 GPIO15、GPIO16 输出锁定为 LOW，确保两路继电器释放。
2. 将 GPIO1、GPIO2 设为输出 LOW 或 0% PWM。
3. 将 GPIO4 配置为输入；图中已有 10k 外部上拉。
4. 将 GPIO5 配置为 ADC 输入，并启用适合约 2.7V 输入的衰减档位。
5. 完成自检、电池电压检查和开关状态确认后，才允许继电器吸合。
6. 停机时先将 PWM 降到 0%，再释放继电器，避免带载切换触点。

## 7. 必须在硬件定版前确认

- 图中 GPIO15/16 似乎直接连接 Q1/Q2 基极，未看到基极限流电阻。若 Q1/Q2 是普通分立 NPN，必须增加合适的基极电阻（常见起点 1k~4.7k，最终按线圈电流和晶体管参数计算）。
- D1/D2 在图中未画成跨接继电器线圈的典型续流二极管连接。应核对 PCB 网络，并确认二极管实际反向并联在线圈两端。
- 原理图只定义 `PWM1/PWM2` 网络，未定义电机接口所需 PWM 频率、极性、最小启动占空比和制动方式。固件开发前需要电机/驱动规格。
- `CB_PIN_STATUS_RGB=GPIO38` 来自所提供的 DevKitC-1 针脚图，不是外接原理图连接；批量硬件若更换开发板版本需重新确认。

## 8. 固件命名约定

后续代码统一引用 `board_pins.h` 中的 `CB_*` 名称，业务代码不得直接散落 GPIO 数字。安全相关逻辑统一使用 `CB_RELAY_ACTIVE_LEVEL`、`CB_RELAY_SAFE_LEVEL`，避免有效电平被写反。
