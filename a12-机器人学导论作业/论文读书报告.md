## 1. 报告摘要

本文针对温室农业场景，提出了一种差速驱动轮式移动机器人的整体设计方案，涵盖机械结构、电机选型、硬件系统架构以及路径跟踪控制策略。论文设计并搭建了一台由铝型材框架、双驱动轮和万向从动轮组成的农业机器人，搭载 Raspberry Pi 4B 与 Arduino Mega 实现感知、决策与电机驱动。

在控制层面，作者对比了三种路径跟踪方案：**Pure Pursuit + PID**、**Stanley + PID** 和 **模型预测控制（MPC）**。实验在三条不同复杂度的参考路径上开展，以最大误差、最小误差和平均横向跟踪误差为评价指标。结果表明，Pure Pursuit + PID 与 MPC 的整体跟踪性能优于 Stanley + PID；综合考虑温室低速作业场景、Raspberry Pi 4B 的计算能力以及实现复杂度，作者最终选用 **Pure Pursuit + PID** 作为实际部署方案。

本报告在研读论文基础上，使用 Python 与 MATLAB 对三种控制器进行了仿真复现，验证了论文的主要结论，并讨论了各控制器的适用条件与局限性。

## 2. 报告正文

### （1）研究背景

现代农业正逐步向自动化、智能化方向发展。温室环境具有通道狭窄、地面相对平整、作业速度较低等特点，非常适合部署轮式移动机器人执行巡检、喷洒等任务。差速驱动（Differential Drive）结构因其机械简单、控制直观、原地转向能力强，成为此类机器人的常用方案。

然而，差速驱动机器人在路径跟踪时面临以下挑战：

- 左右轮独立驱动，容易产生横向偏差和航向偏差；
- 温室路径多为缓弯或直角转弯，控制器需在平滑性与响应速度之间权衡；
- 实际系统算力有限（如 Raspberry Pi 4B），难以承载高复杂度优化控制；
- 低速作业要求控制平稳，避免对作物造成冲击。

因此，如何在**机械设计—硬件架构—控制算法**三个层面进行协同设计，是本文关注的核心问题。

### （2）相关工作

论文回顾了多种路径跟踪控制器：

| 控制器 | 主要思想 | 优点 | 局限 |
|--------|----------|------|------|
| Pure Pursuit | 追踪前方预瞄点 | 实现简单、计算量小、响应灵活 | 预瞄距离敏感，急弯时易切弯 |
| PID | 反馈消除速度/位置误差 | 成熟稳定、易于调参 | 单独使用难以处理非线性路径 |
| Stanley | 联合消除航向误差与横向误差 | 在结构化道路场景中表现稳健 | 低速时易振荡，对曲率变化敏感 |
| MPC | 在有限时域内优化未来控制量 | 可处理约束、预测性强、精度高 | 建模复杂、计算开销大 |

相关研究表明，Pure Pursuit 与 PID 组合在自主导航中应用广泛；Stanley 源于 DARPA 挑战赛 Stanford 车；MPC 虽能获得更优控制，但对处理器和模型精度要求更高。本文的创新点不在于提出全新理论，而在于**面向温室农业机器人，将机械、电气与控制策略作为一个整体系统进行比较与选型**。

### （3）研究方法

#### 3.1 机械与系统设计

**机械结构：**

- 机架采用 4040 铝型材 + T 型槽结构，尺寸约为：高 400 mm（含相机支架）、宽 350 mm、底座高 150 mm；
- 驱动形式：两主动轮 + 一万向轮；
- 设计负载约 30 kg，考虑滚动摩擦系数 μ=0.02、最大坡度 5°，由

  \[
  f = ma + \mu mg + mg\sin\theta, \quad T = fr
  \]

  并取安全系数 4，选型 RCMS 直流减速电机（保持力矩 27 kg·cm）。

**硬件架构：**

- 主控：Raspberry Pi 4B（视觉处理与上层决策）；
- 运动控制：Arduino Mega + Rhino 直流伺服驱动器；
- 感知：摄像头；外接 GPU 计算机辅助图像分析；
- 执行：水泵 + 喷嘴（农业喷洒任务）。

#### 3.2 三种路径跟踪控制器

**（a）Pure Pursuit + PID**

- Pure Pursuit 根据预瞄距离 \(L\) 计算角速度，使机器人朝向前方目标点；
- PID 调节线速度，使实际速度趋近期望速度；
- 特点：结构清晰、适合嵌入式平台。

**（b）Stanley + PID**

- Stanley 通过航向误差与横向误差（Cross-Track Error, CTE）计算转向角：

  \[
  \delta = \theta_e + \arctan\left(\frac{k \cdot e_{ct}}{v}\right)
  \]

- PID 维持线速度稳定；
- 特点：对结构化道路效果好，但在低速和急弯处可能振荡。

**（c）MPC**

- 采用单轮车运动学模型：

  \[
  \dot{x} = v\cos\theta,\quad \dot{y} = v\sin\theta,\quad \dot{\theta} = \omega
  \]

- 在有限预测时域上最小化代价函数（位置偏差 + 控制量惩罚）；
- 特点：精度高，但求解开销大。

#### 3.3 实验评价指标

论文采用以下误差指标：

- 最大误差 \(E_{max}\)
- 最小误差 \(E_{min}\)
- 平均误差 \(E_{avg}\)
- 标准差 \(\sigma\)

横向跟踪误差定义为机器人当前位置到参考路径的欧氏距离。

### （4）实验结果

#### 4.1 论文原始结果

论文在三条路径上对比三种控制器，主要结果如下（单位：米）：

**Path 1**

| 控制器 | \(E_{max}\) | \(E_{min}\) | \(E_{avg}\) |
|--------|------------|------------|------------|
| Pure Pursuit + PID | 1.11 | 0.01 | 0.52 |
| Stanley + PID | 1.13 | 0.06 | 0.59 |
| MPC | 1.18 | 0.00 | 0.54 |

**Path 2**

| 控制器 | \(E_{max}\) | \(E_{min}\) | \(E_{avg}\) |
|--------|------------|------------|------------|
| Pure Pursuit + PID | 1.06 | 0.01 | 0.51 |
| Stanley + PID | 1.07 | 0.00 | 0.54 |
| MPC | 1.09 | 0.03 | 0.51 |

**Path 3**

| 控制器 | \(E_{max}\) | \(E_{min}\) | \(E_{avg}\) |
|--------|------------|------------|------------|
| Pure Pursuit + PID | 1.05 | 0.01 | **0.46** |
| Stanley + PID | 1.04 | 0.00 | 0.48 |
| MPC | 1.05 | 0.03 | **0.46** |

**论文结论：**

1. Pure Pursuit + PID 与 MPC 整体优于 Stanley + PID；
2. Stanley 在急弯和速度变化时偏差更大；
3. MPC 虽精度高，但受 Raspberry Pi 4B 算力限制，工程实现成本较高；
4. 最终选择 **Pure Pursuit + PID** 作为温室低速场景下的实用方案。

**复现分析：**

### （5）研究结论

本文给出了一套面向温室农业的差速驱动机器人完整设计流程：

1. **机械层面**：铝型材模块化机架 + 双电机差速驱动，满足 30 kg 负载与低速稳定运行；
2. **系统层面**：Raspberry Pi 负责视觉与决策，Arduino 负责实时电机控制，结构清晰；
3. **控制层面**：三种路径跟踪策略中，Pure Pursuit + PID 在精度、复杂度、算力需求之间达到最佳平衡；
4. **工程选型**：MPC 适合算力充足且模型精确的场景；Stanley 更适合道路等结构化环境；温室场景优选 Pure Pursuit + PID。

## 3. 总结与讨论

### 3.1 学习收获

通过研读与复现本文，我对机器人系统"整体设计"有了更深入理解：

- 控制器性能不仅取决于算法本身，还与**平台算力、速度范围、路径曲率、执行器特性**密切相关；
- Pure Pursuit 的本质是几何跟踪，直观且鲁棒；MPC 的本质是优化控制，精度高但代价大；Stanley 则强调横向误差与航向误差的耦合消除；
- 在课程所学的**运动学建模、PID 控制、轨迹跟踪**知识，可以直接映射到本文的工程问题中。

### 3.2 复现体会

1. **模型差异**：论文基于真实机器人实验，仿真采用理想运动学模型，因此数值误差不可直接一一对应，但控制器优劣排序可复现；
2. **Stanley 调参敏感**：仿真中 Stanley 对增益、速度软饱和和路径索引策略非常敏感，说明其在低速曲线路径上需要更细致 tuning；
3. **MPC 实现要点**：预测时域、权重矩阵和控制约束对结果影响显著；在 Python 中可用 `scipy.optimize.minimize` 实现短视域 MPC；
4. **工程落地**：论文最终未选择 MPC，体现了"够用即可"的工程哲学——在温室低速任务中，简单可靠的 Pure Pursuit + PID 更具性价比。

### 3.3 可改进方向

- 引入轮地打滑、传感器噪声和执行器一阶滞后，提升仿真真实性；
- 对 Stanley 控制器增加低速增益调度，缓解振荡；
- 使用 ROS/GAZEBO 或 Webots 进行三维可视化仿真；
- 在实物机器人上复现实验，进一步验证论文结论。
