CompositeMapHelper类

地图工具类。

方法

loadFile(String var1)

加载地图文件var1。

Stability: 3 - Stable

Added in v2.5.0

返回值

返回加载的CompositeMap对象，若加载失败返回null。

参数说明
参数名称 参数类型 描述 备注
var1 String 地图文件的路径 暂无
注意事项

无。

示例代码

 CompositeMapHelper compositeMapHelper = new CompositeMapHelper();
 String path = "/sdcard/demo.stcm";
 CompositeMap compositeMap = compositeMapHelper.loadFile(path);。

   

saveFile(String var1, CompositeMap var2)

根据路径保存地图。

Stability: 3 - Stable

Added in v2.5.0

返回值

返回值String，若保存成功返回null，若失败返回表示错误信息的String。

参数说明
参数名称 参数类型 描述 备注
var1 String 路径 一定要给sd卡权限
var2 CompositeMap 地图对象 暂无
注意事项

无。

示例代码

 CompositeMapHelper compositeMapHelper = new CompositeMapHelper();
 String srcPath = "/sdcard/demo_src.stcm";
 CompositeMap compositeMap = compositeMapHelper.loadFile(srcPath);
 String destPath = "/sdcard/demo_dest.stcm";
 String errMsg = compositeMapHelper.saveFile(destPath, compositeMap);
