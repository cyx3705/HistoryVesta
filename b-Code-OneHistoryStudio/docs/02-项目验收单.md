## 节点 V2-M1 —— proj.* 指令域（出口：纯控制台可管理项目库）

> 本节点验收全程**不使用任何工具窗口**，只在控制台手输指令——这是控制台完备性的落点。
> A1-1 ~ A1-6 在沙盒裸仓库执行；A1-8 在生产仓库以只读指令复核。

- [x] **A1-1 列表**（2026-07-14，自动化）
  步骤：`proj.list`，再 `proj.list filter=2026`。
  通过标准：输出与 `git worktree list` 一致；过滤生效；含编号/分支/路径/状态。
  记录：沙盒与生产（34 个 worktree）均验证；filter 包含匹配生效；目录缺失时标注「疑似断链」。
- [x] **A1-2 创建**（2026-07-14，自动化）
  步骤：`proj.create name=9999-901-验收测试`。
  通过标准：分支与同名 worktree 目录生成；基于分支默认 0000-000-Template；
  重复创建、含 `\/:*?"<>|` 的名称、目标目录已存在三种情况分别被明确拒绝且不崩溃。
  记录：沙盒验证创建成功（含 base= 指定基础分支）；重复名/非法字符/目录冲突三类拒绝路径全过。
- [x] **A1-3 提交与大小检查**（2026-07-14，自动化）
  步骤：在测试 worktree 放入普通文件 + 一个 60MB 文件 → `proj.commit name=9999-901-验收测试 msg=验收`；
  再放入一个 110MB 文件重复提交。
  通过标准：60MB → 警告回显但提交成功；110MB → 触发 LFS 流程（无 LFS 环境则明确失败提示；
  确认对话拒绝时该项目跳过，结果为 Rejected 且不产生半截提交）。
  记录：60MB 警告后提交成功；110MB 经 `--yes` 自动确认走通 LFS 全链路（裸仓库内为标准指针
  version/oid/size，.gitattributes track 规则生成）。「拒绝→跳过」分支留人工点否复验。
- [x] **A1-4 推送**（2026-07-14，失败路径自动化；成功路径留真实推送时复验）
  步骤：`proj.push name=<已配置 remote 的测试分支>`。
  通过标准：成功/失败均有明确回显与 ExitCode 判定，失败不吞错。
  记录：无 remote 沙盒推送 → 「退出码 128 + fatal 原文」完整回显。成功路径待首次生产推送确认。
- [x] **A1-5 批量**（2026-07-14，自动化）
  步骤：`proj.commitall msg=批量验收`。
  通过标准：逐项进度回显（n/总数）；结束输出成功/跳过/拒绝/失败四类汇总；全程 UI 不冻结。
  记录：沙盒 2 项目逐项 [n/2] 进度 + 四类汇总输出正确；UI 不冻结由长任务异步机制保证，交互复验留 A5-2。
- [x] **A1-6 删除与保护**（2026-07-14，自动化 + 人工确认框待点验）
  步骤：`proj.delete name=9999-901-验收测试`；再 `proj.delete name=0000-000-Template`。
  通过标准：普通分支弹总线二次确认，确认后 worktree 与分支均消失；
  受保护分支（Template/main/master）在确认之前即被拒绝。
  记录：受保护分支未弹框直接拒绝 ✓；`--yes` 自动确认后 worktree+分支删除 ✓；
  确认对话框的人工「是/否」点击留交互复验。
- [x] **A1-7 继承树与配置**（2026-07-14，自动化）
  步骤：`proj.tree`；`proj.config` / `app.get` 读配置；`app.set` 改仓库路径后 `proj.list`。
  通过标准：树形输出反映真实分支继承关系；配置改动即时生效且重启后保留。
  记录：生产 34 分支继承树 50s 构建成功；沙盒↔生产配置切换同进程即时生效、跨重启保留。
  **修复一处 V1 遗留缺陷**：tip 相同的分支（刚创建未提交的新项目）merge-base 距离互为 0 会互认
  父子成环、从根不可达——已加不可达分量修复（tip 最早者改挂根），沙盒复现并验证修复。
- [x] **A1-8 控制台完备性（本节点总验收）**（2026-07-15，用户人工交互验收通过）
  步骤：生产仓库上，关闭全部工具窗口只留控制台，依次完成：list → tree → create（沙盒名）→
  commit → delete（刚建的沙盒名）。
  通过标准：全流程仅靠手输指令完成，每条均有回显与日志落盘。
  备注：全部指令已在沙盒+生产（只读）自动化验证；用户已亲手交互复验（含确认框点击）。
