# AppShell 0.5.0

0.5.0 是 AppShell 首个可由伞外项目按固定版本消费的本地 NuGet 版本。OHS 仍通过
`ProjectReference` 使用 `b-Code-AppShell` 唯一源码，不切换到包引用。

## 发布内容

- 发布 `OneHistory.AppShell.Core`、`OneHistory.AppShell.Services`、
  `OneHistory.AppShell.Shell` 三个分层包及对应符号包。
- 发布 win-x64、framework-dependent 的 AppShell 演示 ZIP；演示宿主不作为 NuGet 包。
- 建立集中版本与依赖管理、锁文件、SourceLink、XML 文档、包验证、隔离消费测试、
  SHA-256 和 manifest 发布闭环。
- `Microsoft.Data.Sqlite` 升至 8.0.29，并使用 `SQLitePCLRaw.bundle_e_sqlite3` 3.0.4；
  已移除存在 High 公告的 `SQLitePCLRaw.lib.e_sqlite3` 2.x 依赖链。
- 命令手册标题、更新提示和公开 MCP 示例完成通用化；独立宿主不再显示不可用的
  OHS `tool.scan/tool.sync/tool.remove` 入口，OHS 注册对应能力后仍正常显示。
- 设置、日志和 MCP 持久化数字/日期改用 invariant 格式；缓存设置 JSON 序列化选项。
- 收录 OHS 2.4.5 已验收的 MCP `structuredContent` 加法兼容实现，保留旧 `content` 文本块。

## 兼容性

- 目标运行时：.NET 8。
- Shell 目标平台：Windows WPF。
- 演示 RID：win-x64，依赖目标机已安装 .NET 8 Desktop Runtime。
- AvalonDock 保持 4.72.1，未混入布局兼容升级。
- 0.5.0 是首个包兼容性基线，不承诺与未发布为包的 0.4.4 形成 NuGet 二进制基线。

## 验收

- AppShell Debug/Release：0 warning / 0 error。
- OHS Debug/Release：0 warning / 0 error；六套 Smoke 全部通过。
- NuGet 传递依赖漏洞审计：0 项。
- PackageSmoke 仅引用 Shell 包即可获得 Core、Services、Shell，三程序集均为 0.5.0.0。
- 演示应用标题、三主工具窗、通用模块页、`help`、SQLite 初始化和优雅退出均完成验收。

## 发布边界

本版本只进入仓库内本地 feed。未创建 Git tag，未推送 Git 或 NuGet.org；公共发布仍需先确定
许可证并由用户明确授权。
