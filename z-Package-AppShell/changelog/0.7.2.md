# AppShell 0.7.2

0.7.2 将 AppShell 模块界面统一为普通工具窗口，并正式发布 Core、Services、Shell 和 ServiceHost
四个本地 NuGet 包。

## 发布内容

- 删除固定主内容、工作页契约和 `page.list/open/close/activate`。
- 中央区仅保留无标签空背景，不创建任何 `LayoutDocument`。
- 模块 UI 统一通过 `IShellUiRegistrar.RegisterToolWindow` 注册。
- 工具窗口继续支持隐藏、浮动、重新停靠、布局持久化和双击蓝色标题拖动条最大化/恢复。
- 旧布局中的文档节点在恢复时清理，已注册工具窗口尽量保留原布局。
- 新增 ServiceHost 正式包，保持 Core、Services、Shell、ServiceHost 四包同版本。

## 兼容性

- 目标运行时：.NET 8；Shell 与 ServiceHost 仅支持 Windows WPF。
- 本版删除公开工作页类型和成员，是源码及二进制破坏性修订。
- 引用 0.7.1 UI 契约的模块必须改用 `RegisterToolWindow` 并针对 0.7.2 重新编译。
- `page.*` 不提供兼容别名；使用 `win.show/hide/float/dock/max/restore`。
