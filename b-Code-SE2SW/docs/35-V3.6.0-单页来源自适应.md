# SE2SW V3.6.0 单页来源自适应

> 日期：2026-08-04  
> 版本：3.5.7 -> 3.6.0  
> 范围：SE2SW 单页 UI、来源状态、文件夹批量调用链、测试与文档  
> 不涉及：Worker 动词、Contracts JSON、CAD COM、CommandBus、AppShell/OHS 产品代码或正式部署

## 1. 目标

删除“零件转换 / 装配转换 / OHS 兼容”三层页面导航，以原装配页面作为唯一外壳。顶部来源段提供
“选择装配体”和“选择零件文件夹”：前者自动执行既有只读探查，后者扫描目录顶层 `.par` 并批量转换。

此次统一的是页面和 UI 调用链，不删除 OHS 实现，也不改变外部协议。`ConversionMode.Ohs` 数值、
`SE2SWViewModel`、`SE2SWView` 与 `OhsProjectResolver` 保留，未来可以在来源菜单恢复“选择 OHS 项目”。

## 2. 实现

- `AssemblyViewModel` 新增 `None / Assembly / PartDirectory` 来源状态，统一来源路径、输出路径、进度、取消和主按钮；
- 选择 `.asm` 会清空旧文件夹结果，按原路径只探查一次；成功后仍显示装配树与唯一零件双栏；
- 选择文件夹会清空装配树、计划和源哈希，只调用 `FileScanner.Scan(External, ...)` 扫描顶层 `.par`；
- 文件夹页面隐藏装配树，零件表跨越两列；不显示选择框，不支持部分转换；
- 已有 XT 或 SLDPRT（含旧版平铺位置）显示“已存在”，不进入 `BatchRequest`，`Overwrite=false`；
- 扫描只计算 `<目录>\XT` 与 `<目录>\SW` 路径，不创建目录。点击转换并通过 CAD 环境检查后，才调用既有输出目录创建逻辑；
- 文件夹批次结束或取消后自动重扫，成功项变为“已存在”，没有产物的失败项恢复为可重试；
- “识别特征”和“完全定义草图”默认关闭，关闭前者时后者同步取消；
- 文件夹来源强制关闭并禁用“零件失败时继续”和“重建装配关系”。零件 Worker 仍按既有合同逐件继续；
- 运行期间来源按钮禁用；取消文件或文件夹对话框不会调用来源切换方法，因此不改变当前状态。

## 3. 接口边界

窗口 ID 继续为 `se2sw`，模块仍注册一个 AppShell 3.0.3 普通工具窗口。Worker 的 `--request`、
`--probe-assembly`、`--assembly` 动词和 Contracts JSON 均未修改。页面调用不包装为 CommandBus 指令，
不新增 MCP/Web 暴露，也不修改 OHS 或 AppShell。
