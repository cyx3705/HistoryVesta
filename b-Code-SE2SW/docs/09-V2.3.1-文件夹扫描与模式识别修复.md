# SE2SW V2.3.1 文件夹扫描与模式识别修复

> 日期：2026-07-31  
> 范围：文件夹选择、OHS 目录解析、零件列表刷新  
> 兼容性：Worker JSON 合同、CAD COM 转换链、OHS 窗口 ID 和命令均不变

## 问题

SE2SW 默认进入 OHS 兼容模式。用户从文件夹选择器直接选择一个顶层含 `.par` 的普通目录时，旧实现会把该目录当作 OHS 项目根，继续拼接 `b-Module-SE`。解析失败后列表被清空；点击“重新扫描”只会重复同一次错误，因此表现为有零件但始终不显示。

直接选择 OHS 项目的 `b-Module-SE` 本身也有同样问题：旧实现会继续查找第二层 `b-Module-SE`，而不是回推项目根。

## V2.3.1 修复

1. OHS 解析器同时接受项目根目录和该项目的 `b-Module-SE` 目录；选择后者时回推并显示规范化的项目根路径。
2. 默认 OHS 模式下，选择或手动填写普通目录且其顶层存在 `.par` 时，界面自动切换到外界模式并立即扫描；“重新扫描”执行同一判定。此判断只看顶层，与既有非递归扫描边界一致。
3. 若所选目录本身是有效 OHS 项目根，或名字为 `b-Module-SE`，保持 OHS 模式，不改变 GE、SW 的输出映射。
4. 无效 OHS 选择不会被误判为空的外界目录。状态栏明确提示应选择项目根/`b-Module-SE`，或切换外界模式。
5. 状态栏增加完整文本工具提示，窄窗口下即使文字被截断也能查看完整诊断。

## 行为矩阵

| 当前模式 | 所选目录 | 结果 |
|---|---|---|
| 默认 OHS | 含 `b-Module-SE` 的项目根 | 保持 OHS，扫描 SE 目录 |
| 默认 OHS | `b-Module-SE` 本身 | 保持 OHS，回推项目根并扫描 |
| 默认 OHS | 顶层含 `.par` 的普通目录 | 自动切换外界模式并扫描 |
| OHS | 空目录或无效项目目录 | 保持 OHS，显示模式修正提示 |
| 外界 | 任意现存目录 | 保持外界模式，只扫描所选目录顶层 |

## 风险边界

- 不递归扫描子目录，避免同名零件被压平到同一输出路径。
- 自动模式识别不创建、不移动任何目录；真正的 OHS `Unused` 目录移动仍只在用户点击转换并通过全部前置检查后发生。
- 本次不触发 Solid Edge 或 SolidWorks COM，不改变 V2.3.0 的首件 FeatureWorks 修复。
