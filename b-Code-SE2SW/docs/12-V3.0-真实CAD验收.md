## 探针结论

`tools/AssemblyProbe` 先于生产契约升版运行，确认：

- SE 旋转索引 `0,1,2 / 4,5,6 / 8,9,10`，平移 `12..14`；
- SW 旋转 `0..8`，平移 `9..11`，`12=1`；旋转不转置；
- `SubOccurrence.GetMatrix` 已是顶层世界矩阵；手算父子矩阵与该值的最大偏差为 0；
- `AddComponent5`、`Transform2`、`FixComponent`、`SaveAs3` 真机通过；
- 当前默认装配模板 token 为 `~BLANK_ASSY_TEMPLATE.asmdot`，不能直接 NewDocument；门禁临时使用探针从空
  SLDASM 生成的物理 ASMDOT，`finally` 恢复原值。生产模块未打包或硬编码模板。

019 自带 `Unused/b-Module-SE/0-装配体.asm` 与对应 SLDASM 实际为空装配，不能作为位置金标准。
