### 2.1 真机门禁（三层样件 `风滚子.asm`，独立重开核验）

| 档 | 命令 | 结果 |
|---|---|---|
| A 配合重建 | `--rebuild-mates` | **56/56 落位**（53 配合 + 3 接地），失败 0，计数自洽；平移偏差 **2.429e-09 m**、旋转 3.997e-15 |
| B 不重建（回归） | 无附加参数 | 与 3.3.2 逐位一致：22/22、**5.551e-17**，全部组件固定 |
| C 安全重试 | `--reuse-existing --rebuild-mates` | 复用 2 个子装配 + 全部零件产物，只重建顶层：43/43 落位，偏差同 A |

三档共同项：3 个装配节点、3 层、22 个叶组件、源 `.asm`/`.par` 哈希未变、模板已恢复、CAD 进程收束。

固定统计（A / C 档）：`测试装配3 1/2`、`测试装配1 1/4`、`风滚子 2/18`——
每层只剩基准件，外加顶层的 `动量轮`（无关系约束，如实报告）。其余组件全部由配合约束。

**B 档的 5.551e-17 与 A 档的 2.429e-09 差三个数量级，但都远低于 1e-6 阈值。**
差异来自求解器：B 档位置是直接写入的，A 档是配合求解出来的。这是预期行为，
也正是 §3.6 的漂移校验存在的理由。

## 3. 版本单一真源

V3.3.1 建立的 `build/SE2SW.Version.props` 本版首次经历真实升版，验证有效：
改一处 `<SE2SWVersion>3.5.0</SE2SWVersion>`，`SE2SW.dll` 的
`ProductVersion = 3.5.0`、`FileVersion = 3.5.0.0` 与 manifest 同步到位，
不再出现 3.3.0 那次"manifest 升了、`module.list` 还报旧版本"的分叉。

## 5. 默认行为不变

`RebuildMates` 默认 `false`。不勾选"重建装配关系"时，转换行为与 3.3.2 完全一致——
B 档门禁的逐位一致结果就是证据。开关在解析出关系之前禁用，
并在提示里说明原因（未解析 / 本装配体无显式关系 / 可翻译 N 条）。

## 6. 遗留

- 相切、角度、齿轮、凸轮等关系类型本批样件未出现，遇到时报 `MateTypeUnsupported`
  并带回接口名，据此决定下一版补哪类。
- `RangeLow` / `RangeHigh` 限位不映射，见 25 号文档 §1.2。
- 四层及以上嵌套、隐藏件在嵌套下的表现仍未真机覆盖（与本版正交，见 20 号文档 §9）。
