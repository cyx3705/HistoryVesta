# SE2SW V3.1.0 三模式界面美化升级

> 日期：2026-08-01  
> 版本：3.0.2 → 3.1.0  
> 性质：纯界面与导航更新；不修改 Contracts、Worker 协议或 CAD COM 转换逻辑

## 目标

3.0.2 使用“零件/装配页签 → 页面内模式按钮”两层选择。选中页签为了连接内容区而删除下边框，在 AppShell 工具
窗口中视觉上像按钮被截掉一半；零件页与装配页还各自重复显示外界/OHS 状态，增加了界面层级和控件数量。

V3.1.0 把入口收敛为唯一一层、三个同级模式：

1. **零件转换**：原零件转换的外界模式；
2. **装配转换**：现有外界装配转换；
3. **OHS 兼容**：现有 OHS 零件转换。

OHS 装配转换不在本版实现。下一次功能更新可在第三模式内扩展零件/装配能力，不需要再次增加顶层导航。

## 界面调整

### 单层模式栏

- 删除 `TabControl/TabItem` 页签模板和页面内部的模式切换控件；
- 顶部使用完整四边框的三段式模式栏，三项宽度、间距和选中态一致；
- 默认进入“零件转换”，模式索引固定为零件 `0`、装配 `1`、OHS `2`；
- 零件与 OHS 复用同一个零件页面和 ViewModel，切换时显式设置 `ConversionMode.External/Ohs`；
- 装配页面保持独立 ViewModel 与取消生命周期，模式切换不会创建第二套工具窗口。

### 页面减负

- 零件页删除外界/OHS 二级按钮；重新扫描改为紧凑图标按钮；
- 零件表删除可由源文件名和固定输出规则推导的 XT、SLDPRT 两列；
- 装配页删除“外界模式 / OHS 后续”占位按钮和单独的 SLDASM 路径栏；
- 装配零件表同样隐藏可推导的 XT、SLDPRT 列；
- FeatureWorks、草图定义和失败策略收入默认折叠的“转换选项”；
- 保留源选择、状态、警告、装配树、唯一零件、取消和转换等必要工作流控件。

### 视觉规则

- 页面背景统一为浅中性灰，工作区使用白色，主操作使用克制的深绿色；
- 卡片和按钮圆角不超过 6 px；
- 选中模式始终保留完整边框，不再通过缺失下边框连接内容区；
- 表头、分隔线、警告和禁用状态使用独立中性色/琥珀色，避免单一色相铺满界面。

## 验收

### 自动化

`SE2SW.Smoke` 新增三模式合同：

- `PageCount == 3`；
- 默认索引 `0` 且零件 ViewModel 为 `External`；
- 索引 `1` 对应装配页面；
- 索引 `2` 把零件 ViewModel 切换为 `Ohs`；
- 从 OHS 返回索引 `0` 后恢复 `External`，原有目录自动识别发生模式切换时顶层按钮也同步更新；
- 越界索引继续抛出 `ArgumentOutOfRangeException`。

`SE2SW.UiSmoke` 支持 `--assembly`、`--ohs`、`--compact` 与 `--capture`，可分别渲染三个模式。

### 实际渲染检查

三种模式均完成 `1280×820` 桌面尺寸和 `820×620` 紧凑尺寸渲染检查：

- 三段按钮四边完整，选中背景和文字居中；
- 顶部品牌、模式栏、路径输入和操作按钮没有重叠；
- 紧凑尺寸下没有截字、横向溢出或工具栏换行；
- 装配树/唯一零件双栏保持稳定宽度；
- 高级选项默认折叠，主流程首屏明显更清爽。
