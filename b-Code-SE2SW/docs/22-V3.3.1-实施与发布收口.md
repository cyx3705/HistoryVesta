# SE2SW V3.3.1 实施与发布收口

> 日期：2026-08-03
> 发布版本：3.3.1
> 状态：已部署到 OHS 正式模块槽

## 1. 版本定位

V3.3.1 是 V3.3 的质量更新，不改变零件/装配转换算法、COM 调用顺序、FeatureWorks 行为、输出布局或三种页面模式。
V3.3 已通过的嵌套装配 CAD 真机基准继续有效；本次没有改动 CAD 语义，因此没有把一次新的真实转换误记为本版本的验收结论。

## 2. 已实施治理

- 新增 `build/SE2SW.Version.props`，作为 UI、Contracts、Worker 的唯一版本源；三个程序集的程序集版本和文件版本均为 `3.3.1.0`，`ModuleInfo.Version` 从主程序集读取。
- 新增 `eng/Update-SE2SWManifest.ps1`，从 props 生成 `z-SE2SW/module.manifest.json`；脚本显式按 UTF-8 读取无 BOM 文件，避免 Windows PowerShell 的本地代码页破坏清单描述字段。
- 在 Contracts 集中 `SE2SWIdentity`、`WorkerProtocol`、`ConversionPathLayout`、产物类别和复用类别；UI 与 Worker 不再分别维护 Worker 动词、JSON 选项、应用数据子目录、外界 `XT/SW` 布局和输出扩展名。
- `WorkerEvent` 兼容性追加可空 `Artifact`、`ReuseKind`；装配页面依据结构化复用类别呈现，不再解析中文消息中的 `XT` / `SLDPRT`。
- 新增无状态 `ConversionProgressPresenter`，统一两个 ViewModel 的阶段、特征、草图和错误呈现，未改变它们各自的扫描、探查、取消、调度和释放模型。
- 新增 [当前转换合同](00-当前转换合同.md)，把现行行为从历史设计与探针记录中分离。
