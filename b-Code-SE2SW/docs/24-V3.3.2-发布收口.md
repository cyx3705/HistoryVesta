## 实施结果

本次只修复三项质量缺陷：

- 嵌套装配复用不再把计划子项伪报为本次已插入、已固定；新增复用装配及其计划直接组件的单列字段和完成提示；
- 嵌套路径的 `SkippedSuppressed` 改为使用完整 occurrence 清单的真实计数；
- UI / Worker 的外界模式异常提示不再硬编码过期的 `V3.0`。

唯一发布版本源仍是 `build/SE2SW.Version.props`。UI、Contracts、Worker 的程序集版本和
`ModuleInfo.Version` 均为 `3.3.2`；`eng/Update-SE2SWManifest.ps1` 已以 UTF-8 重建
`z-SE2SW/module.manifest.json`，清单版本同为 `3.3.2`。

## 嵌套真机门禁补充（2026-08-03）

V3.3.2 收口时 `AssemblyProductionGate` 只跑过离线 Smoke，三档真机门禁事后补齐，全部通过：

| 档 | 覆盖 | 结果 |
|---|---|---|
| 干净 fixture | 三层嵌套全量生成 | 3 节点 / 3 层 / 22 叶组件，平移偏差 5.55e-17 m、旋转 4.00e-15 |
| `--reuse-existing`（仅零件产物） | 12 个 XT + 12 个 SLDPRT 复用，装配全部重生成 | 通过；`existingPartOutputsUnchanged = true`，虚拟模板 `~BLANK_ASSY_TEMPLATE.asmdot` 自动回退并恢复 |
| `--reuse-existing`（含装配产物） | 保留 2 个子装配 `.SLDASM`，只重建顶层 | 通过；2 个复用 + 1 个重建，最终仍 22/22、5.55e-17 |

第三档需要放开门禁原有的"任何节点产物已存在即拒跑"限制——该限制会让
`AssemblyNodeReusePlanner` 的复用分支永远跑不到。现改为仅在非 `--reuse-existing` 时拒绝，
并把复用前已存在的产物记入 `preexistingAssemblyOutputs`。

**这一档同时补上了 V3.3.2 计数改造留下的缺口**：复用节点的组件数虽然按设计从"本次已插入"
里剥离、只作为计划值单列，但产物本身此前从未被核验过内容。门禁现在会重开每个节点产物、
核对一级组件数与固定状态，并把顶层展开后的 22 个叶组件用 SolidWorks 自己的
`GetTotalTransform` 与 SE 世界矩阵比对——复用产物因此不再是"只验时间戳"的黑盒。
