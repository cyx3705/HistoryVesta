# SE2SW V3.0.2 装配模板与安全重试修复

> 日期：2026-08-01  
> 版本：3.0.1 → 3.0.2  
> 范围：SE2SW 自身 UI、Worker、Smoke 与真机门禁；不修改 AppShell/OHS 产品代码

## 故障结论

现场样件为：

`C:\Users\Administrator\Desktop\临时测试\b-Module-SE\风滚子.asm`

第一次转换已经成功生成 7 个 XT 和 7 个 SLDPRT，但没有生成 `风滚子.SLDASM`。SolidWorks 当前默认装配模板为
`~BLANK_ASSY_TEMPLATE.asmdot`，它是虚拟 token，不是物理文件；生产 Worker 把它直接传给 `NewDocument`，
返回 `null` 后以 `AssemblyTemplateMissing` 结束。再次点击时，3.0.1 的 UI/Worker 又把已有零件产物当作覆盖冲突，
所以只显示“输出已经存在”，掩盖了第一次的模板错误。

## 修复

### 装配模板回退

- 优先保留 SolidWorks 当前默认物理模板；
- 默认值为空、是虚拟 token、文件不存在或 `NewDocument` 返回 `null` 时，枚举 SolidWorks 官方模板目录；
- 标准 `gb_assembly.asmdot` 优先于其他装配模板；
- Worker 事件明确回报实际采用的回退路径；
- 不调用 `SetUserPreferenceStringValue`，不永久改变 SolidWorks 用户设置，也不把厂商模板打包进模块。

本机实际回退路径：

`C:\ProgramData\SOLIDWORKS\SOLIDWORKS 2025\templates\gb_assembly.asmdot`

### 安全重试

每个唯一零件在启动 CAD 前分成三类：

1. 已有有效 SLDPRT：直接参与组装；
2. 只有有效 XT：跳过 Solid Edge 导出，仅执行 SolidWorks 导入；
3. 两者都没有：执行完整 `.par → XT → SLDPRT`。

新分层和旧平铺产物都按上述规则参与复用；旧平铺文件不会迁移，也不会为了满足新目录结构而重复转换。

复用前要求文件非空且时间不早于源 `.par`；XT 还必须通过稳定性和 `FORMAT=text` 校验。空文件、错误 XT、
早于源文件的旧产物一律停止并给出明确错误，不删除、不覆盖、不自动迁移用户数据。目标 SLDASM 已存在且
`Overwrite=false` 时仍拒绝转换。

装配页的规划和前置检查允许已有零件产物进入 Worker 安全判定；界面分别显示“复用 SW”“复用 XT”。普通零件
`--request` 协议及其原有“不覆盖已有输出”行为没有改变。

## 自动化覆盖

`SE2SW.Smoke` 新增以下离线门禁：

- 有效 SLDPRT 直接复用；
- 只有有效 XT 时只导入；
- 无产物时完整转换；
- 空 SLDPRT、过期 SLDPRT、错误 XT、过期 XT 拒绝；
- 零件产物可复用，但已有 SLDASM 仍被 UI/Worker 双重拒绝；
- 虚拟模板从模拟官方目录解析到 `gb_assembly.asmdot`，有效当前模板仍保持最高优先级。
- 有效旧平铺 XT/SLDPRT 直接复用，不迁移、不重复转换。

`AssemblyProductionGate` 新增 `--reuse-existing`，用于真实 CAD 环境下同时验证模板回退、零件哈希不变、装配独立
重开、组件引用、固定状态、矩阵精度和进程收束。
