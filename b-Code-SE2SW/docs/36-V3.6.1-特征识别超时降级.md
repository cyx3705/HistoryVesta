# SE2SW V3.6.1 特征识别超时降级

> 基线：V3.6.0  
> 范围：装配转换和批量零件转换中的 FeatureWorks 单件识别  
> 目标：单个零件识别无进度达到 3 分钟时，跳过识别并以完整哑实体继续，不终止整个装配批次

## 问题

`FeatureRecognitionTimeoutSeconds` 原先只存在于请求合同中，没有在隔离 Worker 外层形成真实的无进度监督。FeatureWorks 的 COM 调用一旦长时间不返回，父 Worker 会一直等待，表现为第三个或后续零件卡住并最终让装配转换失败。

## V3.6.1 行为

- 默认单件识别预算为 `180` 秒；只在父 Worker 收到该零件的 `FeatureRecognition` 事件后开始计时。
- 预算期间没有该零件的新识别事件时，父 Worker 终止当前识别子 Worker，收容其未完成 COM 生命周期。
- 不复用被终止 Worker 的 SolidWorks 文档，也不把半成品交给装配构建器。
- 用同一 XT 启动新的单零件 Worker，关闭 `RecognizeFeatures` 和 `FullyDefineSketches`，走普通导入管线生成完整 `SLDPRT`。
- 哑件生成成功后，零件标记为“未识别/哑实体”，并继续进入现有的装配组件插入、固定和可选配合重建流程；识别件和哑件只在零件导入阶段分流，装配阶段不混用失效文档对象。
- 哑件重建失败时，该零件仍按失败策略计数；默认 `ContinueWhenPartFails=false` 时不生成缺件装配体。

## 合同与实现

- `FeatureRecognitionPolicy.DefaultTimeoutSeconds` 是 180 秒的唯一默认值，保留旧 JSON 字段以兼容历史请求。
- 新增 `ConversionErrorClass.FeatureRecognitionTimeout`，超时、哑件回退和最终完成事件均可审计。
- `SolidWorksPartImportIsolation` 新增 `RecognitionTimedOut` 结果和无 FeatureWorks 回退请求。
- `AssemblyConverter` 继续只按有效 `SLDPRT` 路径生成成功组件清单；嵌套装配与关系重建代码不接收超时 Worker 的 COM 引用。

## 验收

- Release build：通过，0 警告、0 错误。
- `SE2SW.Smoke`：通过；既有装配规划、关系合同、FeatureWorks 隔离与 JSON 回归保持通过。
- 未在当前 SolidWorks 会话上伪造 3 分钟真机等待；真机门禁应使用一个已知会卡住 FeatureWorks 的副本样件，确认超时后生成非空 `SLDPRT`、装配继续构建且源文件哈希不变。

## 边界

本版不修改 Solid Edge 导出、装配矩阵、配合匹配算法或页面选项。超时只针对单零件特征识别无进度，不把用户主动取消、SolidWorks 启动失败或保存失败误判为可降级识别超时。
