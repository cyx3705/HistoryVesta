# SE2SW V3.1.1 装配页空闲状态栏精简

> 日期：2026-08-01  
> 版本：3.1.0 -> 3.1.1  
> 性质：界面补丁；不修改 Contracts、Worker 协议或 CAD COM 转换逻辑

## 问题

装配转换页在没有选择 `.asm`、也没有任务运行时，底部仍固定占用 52 px，显示“请选择 Solid Edge .asm 装配体”
和禁用的“取消”按钮。这一行没有提供有效操作，并压缩了装配树和唯一零件区域。

## 修改

- 将装配页底部状态行从固定高度改为按内容自动布局；
- 空闲时折叠整行，不保留空白高度；
- 探查或转换运行时显示状态、进度条和“取消”按钮；
- 零件转换页、装配转换流程和取消生命周期均不修改。

## 验收

- Release 构建：0 warning / 0 error；
- `SE2SW.Smoke`：PASS；
- 装配模式实际 WPF 渲染确认空闲状态行及其占位均已消失；
- 运行态仍由 `IsBusy` 控制状态行显示，取消入口保持可用。
