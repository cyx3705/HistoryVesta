## 注意事项
- **BOOT**：GPIO0（上电拉低进入下载模式）
- **USB OTG**：GPIO19 (D-) + GPIO20 (D+)
- **RGB LED**：通常接 GPIO38
- **Strapping Pins**：GPIO0, GPIO3, GPIO45, GPIO46
- **电源**：3.3V 逻辑电平
