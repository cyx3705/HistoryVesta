☕ 咖啡冷萃机 - 电路接线说明

ESP32-S3-N16-R8 + 7.4V 锂电池 + 继电器双电机驱动

一、引脚分配总览

电机A 继电器 GPIO4
电机B 继电器 GPIO5
开关1 (启动) GPIO6
开关2 (模式) GPIO7
电池电压检测 GPIO1 (ADC)
状态LED GPIO38 (RGB)
选用 GPIO4/5/6/7 是因为它们位于左排 Pin4~7，没有特殊的 strapping 功能，上电时不影响启动模式，可自由用作通用IO。

二、电源系统

🔋 7.4V 锂电池 → 电源开关 → DC-DC 降压 (5V) → ESP32 5V Pin

电源电路详细

  7.4V 锂电池 (2S)
       │
       ├──────┐
       │    [总电源开关]
       │      │
       ▼      ▼
  ┌─────────────────┐
  │  DC-DC 降压模块  │
  │   MP1584 / 2596  │
  │  输入: 7~28V     │
  │  输出: 5V / 3A   │
  └────────┬────────┘
           │ 5V
           ├─────────────────────→ ESP32 Pin21 (5V)
           │
           ├─────────────────────→ 继电器模块 VCC (5V)
           │
           └─── [100μF 电解电容] ─── GND

  注意: ESP32 DevKit 板载 AMS1117-3.3 将 5V 降为 3.3V
  无需额外 3.3V 稳压器

  7.4V 电池 ──────────────────────→ 继电器公共端 (COM)
  (电机供电直接用 7.4V，不经降压)

所需元器件

  • DC-DC 降压模块 — MP1584EN 或 LM2596 模块，调至 5V 输出（推荐 MP1584 体积小）
  • 总电源开关 — 拨动开关或按键开关，额定电流 ≥ 3A
  • 滤波电容 — 100μF/16V 电解 + 100nF 瓷片，并联在 5V 输出端
  • 7.4V 锂电池 — 2S 锂电池组，建议带保护板（过放/过充/过流）
7.4V 电池满电约 8.4V，放电截止约 6V。MP1584 输入范围 4.5~28V 完全覆盖。LM2596 输入范围 4.5~40V 也可以。

三、电池电压检测 (可选但推荐)

分压电路

  7.4V 电池+ ─── [R1 = 100kΩ] ──┬── [R2 = 47kΩ] ─── GND
                                 │
                                 └──→ GPIO1 (ADC1_CH0)

  分压比: 47 / (100 + 47) = 0.3197
  满电 8.4V → ADC 读到 2.686V (在 3.3V 量程内 ✔)
  低电 6.0V → ADC 读到 1.918V
通过 ADC 读取电压，可以在电池电量低时 LED 闪烁报警或自动停机保护电机。

四、继电器电机驱动

方案：使用现成 5V 继电器模块（推荐）

市面常见的 1路/2路 5V 继电器模块 已集成光耦隔离 + 驱动三极管 + 续流二极管， GPIO 直接接信号端即可驱动，无需额外电路。 

  ┌─────────────────────────────────────────────────────────┐
  │                  2路 继电器模块                          │
  │                                                         │
  │   VCC ←── 5V (来自 DC-DC)                               │
  │   GND ←── GND (公共地)                                  │
  │   IN1 ←── GPIO4 (ESP32 Pin4)     → 控制继电器1 (电机A)  │
  │   IN2 ←── GPIO5 (ESP32 Pin5)     → 控制继电器2 (电机B)  │
  │                                                         │
  │   ┌──────────┐    ┌──────────┐                          │
  │   │ 继电器1  │    │ 继电器2  │                          │
  │   │ COM ─────│──  │ COM ─────│──  ← 7.4V 电池+         │
  │   │ NO ──────│──  │ NO ──────│──  → 电机A+ / 电机B+     │
  │   │ NC       │    │ NC       │    (空)                   │
  │   └──────────┘    └──────────┘                          │
  │                                                         │
  └─────────────────────────────────────────────────────────┘

  电机A- ──→ GND (电池负极)
  电机B- ──→ GND (电池负极)

  工作逻辑（大多数模块低电平触发）:
    GPIO = LOW  → 继电器吸合 → 电机转
    GPIO = HIGH → 继电器释放 → 电机停

继电器模块选型

  • 2路 5V 继电器模块（带光耦隔离）
  • 触点容量 ≥ 10A/250VAC（绰绰有余）
  • 信号输入 3.3V 兼容（大多数模块都兼容）
  • 推荐品牌：宏发 HF32F、松乐 SRD-05VDC

如果使用裸继电器

  • 需自行添加 NPN 三极管 (S8050)
  • 基极串联 1kΩ 电阻到 GPIO
  • 继电器线圈并联 1N4148 续流二极管
  • 详见下方分立元件电路图

备选：分立元件驱动（裸继电器）

                          5V
                          │
                     ┌────┴────┐
                     │ 继电器   │
              ┌──┤ 线圈 5V  │
              │      │         │
              │      └────┬────┘
         1N4148        │
         (续流)         │
              │      ┌──┴──┐
              └──────┤  C  │
                     │     │ S8050 (NPN)
  GPIO4 ──[1kΩ]──── ┤  B  │
                     │     │
                     └──┬──┘
                        │ E
                       GND

  GPIO = HIGH → 三极管导通 → 继电器吸合 → 电机转
  GPIO = LOW  → 三极管截止 → 继电器释放 → 电机停

  (注意：分立电路是高电平触发，与模块的低电平触发相反)

五、开关输入

按键/拨动开关接线

  3.3V ──[10kΩ 上拉]──┬──→ GPIO6 (开关1 - 启动/停止)
                       │
                  [按键开关]
                       │
                      GND

  3.3V ──[10kΩ 上拉]──┬──→ GPIO7 (开关2 - 模式选择)
                       │
                  [拨动开关]
                       │
                      GND

  未按下: GPIO 读到 HIGH (3.3V)
  按下:   GPIO 读到 LOW  (GND)
ESP32 内部有上拉电阻可以用 INPUT_PULLUP 模式，这样可以省略外部 10kΩ 上拉。 但建议保留外部上拉，抗干扰能力更强。

硬件消抖（可选）

  3.3V ──[10kΩ]──┬──→ GPIO6
                  │
             [100nF] ← 消抖电容
                  │
             [按键开关]
                  │
                 GND

  RC 时间常数 = 10kΩ × 100nF = 1ms
  配合软件 20~50ms 消抖，效果更佳

八、Arduino 示例代码

// 咖啡冷萃机 ESP32-S3 控制代码
// 继电器模块: 低电平触发 (LOW=ON, HIGH=OFF)

#define RELAY_MOTOR_A   4   // GPIO4 - 电机A (搅拌电机)
#define RELAY_MOTOR_B   5   // GPIO5 - 电机B (水泵)
#define BTN_START       6   // GPIO6 - 启动按键
#define BTN_MODE        7   // GPIO7 - 模式选择
#define BATT_ADC        1   // GPIO1 - 电池电压 ADC

#define RELAY_ON   LOW
#define RELAY_OFF  HIGH

bool running = false;
unsigned long lastDebounce = 0;

void setup() {
  Serial.begin(115200);

  pinMode(RELAY_MOTOR_A, OUTPUT);
  pinMode(RELAY_MOTOR_B, OUTPUT);
  digitalWrite(RELAY_MOTOR_A, RELAY_OFF);
  digitalWrite(RELAY_MOTOR_B, RELAY_OFF);

  pinMode(BTN_START, INPUT_PULLUP);
  pinMode(BTN_MODE, INPUT_PULLUP);

  analogReadResolution(12);
  pinMode(BATT_ADC, INPUT);
}

float readBatteryVoltage() {
  int raw = analogRead(BATT_ADC);
  float vAdc = raw * 3.3 / 4095.0;
  return vAdc * (100.0 + 47.0) / 47.0;  // 反算真实电压
}

void motorsOn() {
  digitalWrite(RELAY_MOTOR_A, RELAY_ON);
  digitalWrite(RELAY_MOTOR_B, RELAY_ON);
  running = true;
}

void motorsOff() {
  digitalWrite(RELAY_MOTOR_A, RELAY_OFF);
  digitalWrite(RELAY_MOTOR_B, RELAY_OFF);
  running = false;
}

void loop() {
  // 按键消抖 + 切换
  if (digitalRead(BTN_START) == LOW &&
      millis() - lastDebounce > 200) {
    lastDebounce = millis();
    if (running) motorsOff();
    else motorsOn();
  }

  // 低电量保护
  float vBatt = readBatteryVoltage();
  if (vBatt < 6.2) {
    motorsOff();
    Serial.println("低电量! 自动停机");
  }

  delay(10);
}

所有模块共地！ESP32 GND、DC-DC GND、继电器 GND、电池负极 必须连在一起，否则继电器无法正常触发。
继电器模块大多是低电平触发（IN 接低电平继电器吸合）。 购买时确认触发电平，如果是高电平触发，代码中 RELAY_ON/OFF 需互换。
如果电机启动瞬间电流很大（堵转），建议在电机两端并联 100nF 瓷片电容抑制电磁干扰， 防止 ESP32 复位或 ADC 读数跳变。
