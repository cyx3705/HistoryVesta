# ActiveDock V2.3.1：AppShell 桌面坞恢复

## 问题

AppShell 作为有窗口宿主向 UI 模块注入 `IShellUiRegistrar`。旧实现把该注入误判为“桌面侧只注册管理页面”，
因此 `ActiveDockUiModule.CreateUi()` 提前返回，右下角活动坞窗口没有创建。模块命令和 `dock.manager` 页面仍能正常加载，
但用户看不到桌面坞。

## 修复

- 桌面 Shell 宿主继续注册 `dock.manager` 工具窗口。
- 同一生命周期内同时创建右下角 `DockWindow`，保留置底、点击和尺寸调整行为。
- 无窗口的 Smoke 调用只验证注册器，不创建 WPF 窗口，避免测试依赖 STA/UI 环境。
- 服务宿主仍关闭 UI 模块，不创建重复桌面窗口。
- 模块版本升至 `2.3.1`，命令域 `dock` 与 15 条指令不变。

## 验收

- AppShell `module.list` 显示 `dock 2.3.1`。
- AppShell 前端同时出现 `dock.manager` 和桌面右下角活动坞。
- `dock.hide` / `dock.show` 通过共享 `state.json` 控制桌面窗口。
- `DestroyUi()` 同时释放管理页句柄并关闭桌面窗口。
- Release 构建与 ActiveDock Smoke 通过。
