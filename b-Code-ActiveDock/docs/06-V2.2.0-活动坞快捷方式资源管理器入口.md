# ActiveDock V2.2.0：活动坞快捷方式资源管理器入口

## 目标

资源管理器“此电脑”中的“`OHS 项目`”不再直接暴露整个
`C:\OneHistory\OneHistory-Projects` 工作树。模块在其自身部署目录中维护
`快捷方式\`，其中仅包含活动坞当前展示项目的 Windows `.lnk` 文件；资源管理器
入口改为指向该受控目录。

## 同步规则

- 快捷方式目录固定为 OHS 的正式模块槽
  `%APPDATA%\OneHistoryStudio\Modules\ActiveDock\快捷方式`。不依赖 DLL 当前加载位置，
  因而不会被 OHS 热重载的临时影子目录误导。
- 每次扫描、排除项目、调整显示策略或固定项目后，使用同一份最终活动坞列表重建
  `.lnk` 集合。
- 已不在活动坞列表中的 `.lnk` 会移除；非 `.lnk` 文件不会触碰。
- 每条快捷方式指向项目根目录，名称取项目文件夹名称。
- 首次 UI 生命周期与 `dock.explorerRegister` 也会同步目录后再更新 Explorer 注册。

## 边界与验收

- 仅注册“此电脑”命名空间，不修改用户的“快速访问”固定项。
- 不再注册完整工作树根目录。
- `dock.explorer` 返回受控快捷方式目录。
- 冒烟测试验证生成、移除及 Explorer 注册的测试隔离；测试不允许改写真实注册目标。
