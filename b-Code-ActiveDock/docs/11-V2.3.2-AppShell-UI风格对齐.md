# ActiveDock V2.3.2：AppShell UI 风格对齐

## 更新范围

V2.3.2 是桌面活动坞的 UI 质量更新。模块继续由 AppShell 或 OHS 宿主加载，保持现有 `dock` 指令、右下角定位、置底层级、项目扫描、快捷方式同步和管理窗口注册行为不变。

本版本将桌面坞和 `dock.manager` 管理页接入 AppShell 的运行时视觉令牌：宿主提供令牌时跟随宿主主题，独立加载或旧宿主缺少令牌时使用稳定的深色回退色，不要求调用方额外配置资源字典。

## 视觉契约

- Surface、SurfaceAlt、Hover、Pressed、ControlBorder、TextPrimary 和 TextSecondary 从 AppShell 资源读取。
- Accent、AccentHover、TextOnAccent 用于 OHS 入口和主要操作按钮；列表选中态使用 AccentSoft。
- 控件统一采用 28px 高度、8px 内圆角和宿主的 `Shell.Space.ControlPad`，默认内边距为 `10,4,10,4`。
- 字体优先读取 `Shell.Font.Family`、`Shell.Font.Body` 和 `Shell.Font.Small`，缺失时回退到 Microsoft YaHei UI / Segoe UI 以及 13 / 11px。
- 桌面坞项目按钮、空列表提示、右键菜单和管理页列表使用同一套文字、背景、悬停与按下状态。

## 兼容性边界

- 不改变 DockWindow 的无边框窗口、右下角锚定、置底和拖动/缩放命中区。
- 不改变 `dock.manager`、`dock.show`、`dock.hide` 等既有注册和指令行为。
- 不新增 AppShell API 依赖；仅通过 `Application.Current.TryFindResource` 读取可选资源。
- 不创建或修改 OHS 的产品代码，不向 OHS evidence 上抛模块实现文档。

## 验收门禁

1. AppShell 宿主中桌面坞和管理页颜色、字体、圆角、控件高度与宿主约定一致。
2. 缺少 AppShell 资源时桌面坞和管理页仍可创建，且不会因资源缺失抛异常。
3. 管理页列表选中、按钮悬停/按下/禁用状态可见，长项目名不改变布局。
4. ActiveDock Smoke、Release build 和版本/清单一致性检查通过。
5. 部署后 `module.list` 显示 `dock 2.3.2`，桌面坞仍在主显示器工作区右下角并保持置底。

## 版本

本版本统一更新 `ActiveDock.csproj`、`ModuleInfo.Version`、`z-ActiveDock/module.manifest.json` 和 Smoke 版本断言至 `2.3.2`。命令数量、模块 ID 和 AppShell Core 固定依赖版本保持不变。
