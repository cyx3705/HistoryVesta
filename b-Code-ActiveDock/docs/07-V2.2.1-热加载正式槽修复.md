# ActiveDock V2.2.1：热加载正式槽修复

V2.2.0 已完成“活动坞列表 → `.lnk`”的同步逻辑。实际部署核验发现，OHS 热加载会从
`OneHistory-Push` 的影子副本执行程序集；若按程序集位置推导路径，资源管理器会指向临时目录。

本补丁将快捷方式目录固定到：

`%APPDATA%\OneHistoryStudio\Modules\ActiveDock\快捷方式`

因此此电脑入口与实际部署槽一致。测试环境通过
`ACTIVEDOCK_DISABLE_EXPLORER_REGISTRATION=1` 禁止真实目录和注册表副作用；独立的临时
目录测试继续验证 `.lnk` 的增删同步。
