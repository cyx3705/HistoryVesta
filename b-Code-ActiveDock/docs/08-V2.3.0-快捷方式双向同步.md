# ActiveDock V2.3.0：快捷方式双向同步

`%APPDATA%\OneHistoryStudio\Modules\ActiveDock\快捷方式` 不再是单向导出的展示目录，
而是活动坞的原生资源管理器编辑入口。

## 双向规则

- 活动坞刷新、筛选、排除、固定和策略变化仍会重建快捷方式集合。
- 用户删除受控 `.lnk` 后，对应项目会从活动坞排除并移除固定状态。
- 用户新增或改写 `.lnk` 后，若目标是当前 OHS 工作树根目录下且名称符合项目编号规则的项目根目录，
  则该项目会加入、解除排除并固定到活动坞。
- 无效、断开、指向工作树外或命名不符合项目规则的链接不会进入活动坞，并会在下一轮同步清理。
- 手工使用非规范名称新增的有效链接会被替换为标准项目文件夹名的 `.lnk`。

## 实现约束

- 使用防抖的 `FileSystemWatcher` 监听 `.lnk` 创建、删除、改名和改写。
- 自动同步完成后更新期望快照，避免把模块自己的文件操作回写为用户操作。
- 状态仍落在 `state.json`，由既有跨进程监视同步到活动坞与管理页面。
