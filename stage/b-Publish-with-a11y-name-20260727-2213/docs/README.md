# OneHistoryStudio 使用说明

> 适用版本：OneHistoryStudio V2.7.0

OneHistoryStudio 是面向个人项目库的 Git 工作树管理、历史查看、文件规则管理、命令执行和模块扩展工具。程序界面与控制台共用同一套指令注册表，因此按钮、脚本、Help 和 MCP 工具具有一致的命令语义。

V2.6.0 起产品由两个进程组成：`OneHistoryStudio.Service.exe` 是唯一的数据、命令、模块、
MCP 与 Web 宿主；`OneHistoryStudio.exe` 是可随时关闭和重开的 WPF 客户端。关闭前端不会停止服务，
显式执行 `svc.stop` 才会停止后台服务。

## 主要窗口

- **项目总览**：浏览、搜索、选择和打开项目。
- **继承树**：查看项目分支的继承关系，并把所选项目同步到其他窗口。
- **项目操作**：创建项目，提交或推送当前/全部项目，管理 Git 文件格式规则。
- **分支历史**：查看分叉点、提交、HEAD 和远端状态，并预览提交详情与差异。
- **命令集**：搜索全部指令，按域、来源和 MCP 可见性筛选。
- **指令详情**：查看所选指令的参数、示例、风险和 MCP 映射。
- **模块管理**：查看当前加载的扩展模块。
- **控制台**：输入指令并查看统一回显；按 Ctrl + 反引号键可快速聚焦。

中央区域支持模块工作页。已安装的 SE2SW 2.2.0 会作为“SE2SW 格式转换”标签嵌入主窗口，不再弹出
独立窗口。双击页面内容上方带点的蓝色标题拖动条可铺满主窗口，再次双击同一标题条恢复；不要双击更上方
的标签。模块工作页可从蓝色标题条拖出为普通浮动窗口，并可重新停靠。控制台也可执行
`win.max name=se2sw` 和 `win.restore`；使用 `page.list` 查看工作页，`page.open id=se2sw` 激活 SE2SW 页面。

## Help 和命令

在控制台输入：

```text
help
help command=proj.list
command.list
command.show name=proj.list
```

`help` 列出全部可用指令；指定命令名后显示参数和示例。`command.list` 适合搜索和筛选，`command.show` 显示单条指令的完整元数据。按钮操作也会回显对应命令，便于复用到脚本。

## 项目操作原则

- 项目选择来自项目总览或继承树，并同步到项目操作和分支历史。
- 提交、推送、回滚、硬重置和强推等写操作必须先看清项目名、范围与确认提示。
- 分支历史默认读取本地 Git 信息；只有显式刷新远端时才访问远端。
- Git 文件规则只在用户明确应用时写入，不会因为浏览页面自动提交或推送。
- 遇到脏工作树、路径越界、受保护分支或远端状态不明确时，程序会优先拒绝危险操作。

## MCP

MCP 网关只监听本机回环地址，默认端口为 `8737`，并随后台服务启动自动监听。在控制台执行：

```text
mcp.status
```

只有显式关闭自动启动、手动停止或启动失败后才需要执行 `mcp.start`。前端关闭后网关仍可用。需要远程工具接入时，
先阅读《MCP 接入与安全》，确认暴露策略、令牌和危险指令确认模式。

正式 Web API 默认监听 `127.0.0.1:8738`，提供 `/api/health`、`/api/commands`、
`/api/command`、`/api/events` 和 `/api/confirm`。Web 客户端必须配置并发送 Bearer token；
局域网绑定还会强制检查非空 token。

## 扩展模块

模块 DLL 放入当前模块目录后由程序自动装载，文件变化会触发热重载。使用：

```text
module.list
module.open
module.reload
```

模块新增后，程序内的 Help 与命令集会刷新；部分 MCP 客户端会缓存工具目录，需要新建任务或重启客户端后才显示新工具。
