# SWuse 当前构建合同

> 当前发布线：V0.1.0（已实现并完成真实 CAD 验收，未部署）

## 运行模型

1. 用户选择一个本地工作区，编辑其中的多个 `.cs` 文件；
2. UI 保存后将完整源文件清单、入口类型和目标 `.SLDPRT` 写成 JSON 请求；
3. 独立 x64 STA `SWuse.Worker` 用 Roslyn 编译工作区源码；
4. Worker 只允许用户代码引用 .NET 运行库与 `SWuse.Api`；
5. 编译成功后，Worker 在自身进程内启动/连接 SolidWorks COM，执行唯一入口 `PartProgram.Build`；
6. Worker 按请求保存 `.SLDPRT`，回传结构化结果、诊断与日志摘要。

UI、AppShell 模块宿主和 SolidWorks COM 对象之间不跨进程传递 COM 引用。

Worker 不依赖不稳定的 IDispatch 名称解析，而是在运行时从 SolidWorks COM 注册的本地服务器目录加载官方
`SolidWorks.Interop.sldworks.dll`，再经接口反射调用最小 COM 集合。这样不把厂商 Interop DLL 复制进模块，
也能兼容当前工作站 IDispatch 返回 `TYPE_E_ELEMENTNOTFOUND` 的情况。

## 代码模型

工作区可以包含任意数量的帮助类和一个或多个 `PartProgram` 类型。必须恰有一个类型带 `[SwuseEntry]`；
它是本次构建入口。草图与特征使用受控句柄表达依赖：

```csharp
[SwuseEntry]
public sealed class DemoPart : PartProgram
{
    public override void Build(PartBuilder part)
    {
        var outline = part.Sketch("Base", ReferencePlane.Front, sketch =>
            sketch.CenteredRectangle(0, 0, 0.06, 0.04));
        part.Extrude("BaseBoss", outline, 0.01);
    }
}
```

线性尺寸单位固定为米，角度单位预留为弧度。`SketchRef`、`FeatureRef` 只能由 `PartBuilder` 创建，
用户类可传递和复用它们，但不能绕过 API 直接保存 SolidWorks COM 引用。

## V0.1 指令集

| API | 作用 |
| --- | --- |
| `PartBuilder.Sketch` | 在 `Front/Top/Right` 基准面开启并结束草图 |
| `SketchBuilder.Line/Circle/Rectangle/CenteredRectangle` | 创建二维几何 |
| `PartBuilder.Extrude` | 盲深凸台拉伸 |
| `PartBuilder.CutExtrude` | 盲深切除拉伸 |

当前不提供装配、配合、选择过滤器、尺寸约束、圆角/倒角、特征重编辑、任意 SW COM 对象或外部 DLL 引用。

## 文件与覆盖规则

- 源码只读取工作区内、扩展名为 `.cs` 的文件；
- 目标必须是绝对 `.SLDPRT` 路径；点击“生成模型”才创建输出父目录；
- 默认拒绝覆盖已有目标，V0.1 UI 不提供覆盖开关；
- “构建验证”只编译，不启动 SolidWorks，也不创建输出目录；
- Worker 不修改源文件；构建结束后会释放自己创建的 SolidWorks 进程和 COM 引用。

SolidWorks 默认模板可能是 `~BLANK_PART_TEMPLATE.prtdot` 一类虚拟 token，不能直接用于 `INewDocument2`。
Worker 先尝试有效的当前物理 `.prtdot`；否则从 SolidWorks 安装目录和
`%ProgramData%\SOLIDWORKS\SOLIDWORKS *\templates` 中选择物理模板，优先 `gb_part.prtdot`。这不会修改
用户的默认模板设置。标准前/上/右基准面也不依赖英文显示名，而是按新零件前三个 `RefPlane` 的标准顺序直接选择，
因此可用于中文界面。

## 窗口与模块合同

`SWuseUiModule` 实现 `IUiModule + IShellUiAware`，但不使用停靠注册器：

- 注入 `IShellUiRegistrar` 表示运行在桌面 Shell，立即弃权；
- 未注入表示无窗服务宿主，在其 Dispatcher 创建 `swuse` 自持顶层窗口；该窗口显示在任务栏、可获得焦点并按普通桌面窗口编辑；
- 窗口关闭时隐藏，模块卸载时才真正关闭并停止进行中的 Worker；
- `swuse.show`、`swuse.hide`、`swuse.status` 是本模块公开指令，MCP 清单为 `hidden`。
