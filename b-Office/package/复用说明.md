# AppShell 文档包复用说明

本目录是 AppShell 3.1.10 候选消费合同的编辑源。3.1.8 不作为稳定支持版本；其他项目和 AI
继续以 3.1.9 Z 快照为稳定入口。若只需要使用正式宿主或开发嵌入页面，应先读取
`../../z-Package-AppShell/AppShell.reuse.md`，再按其中链接读取同版本 `docs/`；不要扫描源码、
历史发布归档或内部施工文档推断用法。

3.1.10 对 3.1.9 已承接的“轻松指令”做内部高内聚重构。它是宿主 Shell 的视图行为：控制台自身聚焦时使用
`Shift+W`/`Shift+S` 选择候选、`Tab` 确认；
普通布局由控制台文本直接过滤中央命令集，使用 `Shift+W/S` 选择列表、`Tab` 回填命令名；命令集不再提供独立搜索框。
控制台候选、命令集列表与详情共享同一个命令目录会话，数据仍以 `command.list` / `command.show` 为准。
消费方不需要复制候选引擎、Popup、检索或键盘接线，也不应在自己的模块中创建第二套快速指令面板。

## 源码维护读取顺序

1. 根 `AGENTS.md` 与 `project.manifest.json`。
2. `../current/项目概览.md`，确认冻结状态和任务边界。
3. 按任务读取 `技术合同.md`、`有效决策.md` 或 `验证合同.md`。
4. 涉及公开 API、命令、模块、MCP 或消费升级时，再读取本目录对应合同。

## 发布流向

- 编辑源：`b-Office/package/`。
- 候选副本：`b-Publish/current/docs/`。
- 正式历史：`b-Publish/history/<版本>/docs/`。
- 当前正式副本：`z-Package-AppShell/docs/`。

副本由发布脚本复制并校验 SHA-256，不得直接编辑。升级手册、版本记录、审查和施工证据是内部
维护资料，不随消费合同发布。
