## 2. 完整旧 → 新映射（32 条）

### 2.1 `core` → `command`（3 条）

| 3.3.1 | 3.3.2 |
|---|---|
| `vulcan.core.help` | `vulcan.command.help` |
| `vulcan.core.run` | `vulcan.command.run` |
| `vulcan.core.history` | `vulcan.command.history` |

`core` 是 3.2.1 遗留的兜底类名，语义上与 `command` 完全重叠，整类退役。

### 2.2 `frontend` → `app`（3 条）+ `app.exit` 改名（1 条）

| 3.3.1 | 3.3.2 | 说明 |
|---|---|---|
| `vulcan.app.exit` | `vulcan.app.quit` | 退出整个应用（含后台服务） |
| `vulcan.frontend.exit` | `vulcan.app.close` | 只关闭前端窗口，后台继续运行 |
| `vulcan.frontend.show` | `vulcan.app.show` | 唤出前端进程窗口 |
| `vulcan.frontend.hide` | `vulcan.app.hide` | 隐藏前端进程窗口 |

`exit` 同时表示「退应用」和「关前端」是 3.3.0 硬切时留下的歧义，靠 `app`/`frontend`
两个类名区分，删掉类名就撞车。3.3.2 用 `quit`（终止进程树）与 `close`（关闭窗口）拆开。

> `vulcan.app.show` / `vulcan.app.hide`（前端**进程**窗口）与
> `vulcan.ui.show` / `vulcan.ui.hide`（Shell 内**停靠窗口**）是两组不同指令，
> 靠类段区分，不要混用。

### 2.3 `win` + `layout` + `panel` → `ui`（21 条）

窗口（11 条，`win.list` 改名，其余方法段不变）：

| 3.3.1 | 3.3.2 |
|---|---|
| `vulcan.win.list` | `vulcan.ui.windows` |
| `vulcan.win.show` | `vulcan.ui.show` |
| `vulcan.win.hide` | `vulcan.ui.hide` |
| `vulcan.win.float` | `vulcan.ui.float` |
| `vulcan.win.floatstate` | `vulcan.ui.floatstate` |
| `vulcan.win.autohide` | `vulcan.ui.autohide` |
| `vulcan.win.dock` | `vulcan.ui.dock` |
| `vulcan.win.max` | `vulcan.ui.max` |

| `vulcan.win.reset` | `vulcan.ui.reset` |
| `vulcan.win.restore` | `vulcan.ui.restore` |

布局（4 条）：

| 3.3.1 | 3.3.2 |
|---|---|
| `vulcan.layout.list` | `vulcan.ui.layouts` |
| `vulcan.layout.save` | `vulcan.ui.layoutsave` |
| `vulcan.layout.load` | `vulcan.ui.layoutload` |
| `vulcan.layout.reset` | `vulcan.ui.layoutreset` |

面板与对话框（6 条）：

| 3.3.1 | 3.3.2 |
|---|---|
| `vulcan.panel.list` | `vulcan.ui.panels` |
| `vulcan.panel.show` | `vulcan.ui.panelshow` |
| `vulcan.panel.set` | `vulcan.ui.panelset` |
| `vulcan.panel.reload` | `vulcan.ui.panelreload` |
| `vulcan.panel.selectfile` | `vulcan.ui.selectfile` |
| `vulcan.panel.selectdirectory` | `vulcan.ui.selectdirectory` |

**为什么部分方法段出现 `layout*` / `panel*` 复合词**：三类合并后有四组方法段直接碰撞——
`list`（win/layout/panel 三方）、`show`（win/panel）、`reset`（win/layout）、
外加 `reload` / `set` 与其他类的阅读歧义。处理方式是：

- 三个列表命令改为**复数名词**：`ui.windows` / `ui.layouts` / `ui.panels`，
  语义比 `list` 更准确，且天然不碰撞；
- 窗口动词是 `ui` 类的**主干**，保留裸方法段（`show`/`hide`/`reset`/`float`…）；
- 布局与面板作为**从属子域**，用「子域 + 动作」复合方法段消歧
  （`layoutsave`、`panelshow`…）。

这是合并到九类必须付出的代价：`ui` 成为最大类（21 条），方法段不再追求最短。
已在 DEC-023「后果」中记录。`selectfile` / `selectdirectory` 是通用文件对话框，
本来就与「面板」无关，归入 `ui` 后语义反而变准确，因此不加前缀。

### 2.4 无类指令归类（5 条）

| 3.3.1（两段式无类） | 3.3.2 | 归属理由 |
|---|---|---|
| `vulcan.listshortcuts` | `vulcan.app.shortcuts` | 只读查阅宿主上已注册的全局快捷键；注册与派发仍归 Mercury |
| `vulcan.listcorrections` | `vulcan.prompt.corrections` | 提示词治理读侧 |
| `vulcan.listincidents` | `vulcan.prompt.incidents` | 提示词治理读侧 |
| `vulcan.proposecorrection` | `vulcan.prompt.correct` | 提示词治理写侧 |
| `vulcan.recordincident` | `vulcan.prompt.record` | 提示词治理写侧 |

「无类」概念随本次对齐一并废止：`CommandRegistry.LegacyClass` 不再对两段式返回空串，
`CommandClassNames`（含 `NoneLabel` = 「无类」与 `CatalogDisplay`）整体退役，
目录、控制台补全和命令集的类筛选不再需要「无类」特例分支。

### 2.5 逃逸域收回（1 条）

| 3.3.1 | 3.3.2 |
|---|---|
| `debug.logflood` | `vulcan.log.flood` |

`debug` 是唯一一个没有任何所有者、仅因命令名首段推导而产生的「影子域」。
它使 `vulcan.command.domains` 长期多报一个域，也让「一个模块一个域」（DEC-020）失真。
承压注入本质是日志子系统的测试入口，收回 `vulcan` 域的 `log` 类。

### 2.6 未改动（51 条）

`log` 原有 10 条、`mcp` 11 条、`module` 4 条、`svc` 4 条、`web` 5 条、
`command` 原有 5 条、`app` 原有 6 条（`about`/`get`/`set`/`opendata`/`theme`/`window`）、
`prompt` 原有 4 条，共 51 条命令文本不变。
