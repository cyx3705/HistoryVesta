# HistoryVulcan 3.3.0 命令硬切映射

本文件登记 3.3.0 旧→新命令名，供其他模块与外部脚本对齐。历史文档正文不回改。

## 规则

- 新名：`vulcan.<类>.<方法>`，全小写，方法段无连字符。
- Domain 元数据：`vulcan`。
- 不留别名；`cls` 删除，仅保留 `vulcan.log.clear`。

## 映射（摘要）

| 旧 | 新 |
| --- | --- |
| `help` / `history` / `run` | `vulcan.core.help` / `vulcan.core.history` / `vulcan.core.run` |
| `cls` | （删除） |
| `log.*` | `vulcan.log.*` |
| `win.float-state` | `vulcan.win.floatstate` |
| `win.*` | `vulcan.win.*` |
| `app.frontend.focus-console` | `vulcan.frontend.focusconsole` |
| `app.frontend.show/hide/exit` | `vulcan.frontend.show/hide/exit` |
| `app.*` | `vulcan.app.*` |
| `command.copy-example` | `vulcan.command.copyexample` |
| `command.list/show/domains/manual` | `vulcan.command.*` |
| `panel.select-file` | `vulcan.panel.selectfile` |
| `panel.select-directory` | `vulcan.panel.selectdirectory` |
| `panel.*` / `layout.*` / `module.*` | `vulcan.panel.*` / `vulcan.layout.*` / `vulcan.module.*` |
| `web.*` / `svc.*` / `shortcut.list` | `vulcan.web.*` / `vulcan.svc.*` / `vulcan.shortcut.list` |
| `mcp.*` / `prompt.*` / `correction.*` / `incident.*` | `vulcan.mcp.*` 等 |

完整运行时清单以 `vulcan.command.list` 为准。
