# V4 探索模型

## 页面与层

一个页面就是一个前端模块。AppShell 和 Web 是特殊的表面模块：它们负责承载、导航、页面嵌入和页面间状态，不作为单独业务页面出现。

## 调用路径

```text
前端页面模块 -> 命令合同 -> MyAPI 命令管线 -> 后端模块
                                      ├─ 本地适配
                                      ├─ HTTP 适配
                                      └─ MCP 适配
```

前端不引用后端项目实现，后端也不引用 WPF、Web 或具体页面。命令合同是两侧唯一稳定耦合点。

## 迁移策略

先把 Lite 的模块快照和反射调用拆成可测试的注册/执行内核，再增加显式命令注册、权限和审计；最后由 AppShell 作为独立前端宿主模块消费。任何阶段都不修改 AppShell 3.0.3。
