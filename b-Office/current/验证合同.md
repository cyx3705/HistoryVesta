# AppShell 验证合同

## 验证原则

- 命令权威声明位于根 `project.manifest.json`；本文解释验证层级、环境和证据。
- 3.0.3 冻结门禁不得因 runner 差异而删除或弱化测试；3.1.1 至 3.1.7 新增合同不得绕过冻结门禁。
- CI 验证源码与冻结合同，不执行正式发布、打标签、推 NuGet.org 或消费方部署。
- 未执行、失败、偶发失败和不适用必须分别记录；重跑通过不得抹去首次失败原因。

| 编号 | 适用时机 | 命令或步骤 | 通过标准 |
| --- | --- | --- | --- |
| VERIFY-FAST | 文档或公开面相关修改 | `b-Code-AppShell/eng/Test-ProjectContract.ps1 -Instantiation` 与 `Assert-PublicApiBaseline.ps1` | 合同无错误，四份 Unshipped 无有效条目 |
| VERIFY-FULL | 源码、工具链或冻结元数据修改 | 锁定还原；Debug/Release build+test；`dotnet format --verify-no-changes` | 双配置 0 warning/0 error，各 142/142，格式通过 |
| VERIFY-CI | 每次推送或人工触发 | `.github/workflows/appshell-freeze-gate.yml` | Windows runner 全步骤成功，TRX 上传 |
| VERIFY-HOST | 宿主、消费文档或部署脚本修改 | `Publish-AppShellHost.ps1 -Version 3.1.7` | `AppShell.exe` 为 3.1.7.0，宿主、全部清单文档和 SHA-256 完整 |
| VERIFY-RELEASE | 正式宿主部署前 | 宿主候选审查、人工批准后 `-DeployToZ` | `b-Publish/current` 与 `z-Package-AppShell` 文件和 SHA-256 一致 |

## 完整本地门禁

```powershell
dotnet restore .\AppShell.sln --locked-mode
dotnet build .\AppShell.sln -c Debug --no-restore
dotnet test .\b-Code-Tests\AppShell.Tests\AppShell.Tests.csproj -c Debug --no-build --no-restore
dotnet build .\AppShell.sln -c Release --no-restore
dotnet test .\b-Code-Tests\AppShell.Tests\AppShell.Tests.csproj -c Release --no-build --no-restore
dotnet format .\AppShell.sln --verify-no-changes --no-restore
powershell -NoProfile -ExecutionPolicy Bypass -File .\b-Code-AppShell\eng\Assert-PublicApiBaseline.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\b-Code-AppShell\eng\Test-ProjectContract.ps1 -Instantiation
```

## CI 合同

- 触发：推送到 `2026-023-AppShell`，或 `workflow_dispatch`。
- Runner：`windows-latest`，超时 30 分钟，仓库权限只读。
- 工具链：`global.json` 固定 SDK 9.0.315；官方 Action 使用 Node 24 兼容主版本。
- 顺序：锁定还原、Debug build/test、Release build/test、格式、公开 API、失败摘要、TRX 上传。
- 失败证据：`Write-TrxFailureAnnotations.ps1` 将失败用例和错误首行写入注释与 job summary；
  `appshell-test-results` 制品保存 Debug/Release TRX。
- 边界：不调用 `Publish-AppShellHost.ps1 -DeployToZ` 或 `Publish-AppShell.ps1 -Publish`，不访问下游工作树，不写正式发布目录。

## 环境前提

- Windows 10/11 或 GitHub Windows runner；WPF 测试需要 STA/Dispatcher 支持。
- .NET SDK 9.0.315；目标运行时为 .NET 8。
- NuGet 仅使用仓库 `nuget.config` 声明的 nuget.org；还原必须使用锁文件。
- 本机 CET 不兼容时可设置 `DOTNET_EnableWriteXorExecute=0`；CI 不携带该机器特例。

## 证据保存

| 证据 | 位置 | 入库 | 保留规则 |
| --- | --- | --- | --- |
| 本地/冻结执行证据 | `b-Office/history/` 或正式冻结证据 | 是 | 随对应版本长期保存 |
| CI 状态 | GitHub Actions `AppShell Freeze Gate` | 外部 | 按仓库 Actions 保留策略 |
| CI TRX | `appshell-test-results` artifact | 外部 | 按 Actions 制品保留策略 |
| 候选产物与测试结果 | `b-Publish/current/` | 否 | 只保留最近一次，可覆盖、可重建 |
| 正式最小历史副本 | `b-Publish/history/<版本>/` | 是 | 与当时 Z 快照同构且不可覆盖 |
