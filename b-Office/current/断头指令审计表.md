# AppShell 3.1.7 断头指令审计表

本表盘点会改变应用状态或执行外部操作的 UI 入口。业务入口必须通过 `CommandBus.ExecuteAsync`；纯焦点、
选择和 Tab 导航属于视图交互，不单独注册业务命令。命令名称以运行时 `command.list` 为最终真值。

| 文本框自身焦点、列表选择、Tab 导航 | 无 | 视图交互 | 视图行为测试 | 不显示/隐藏窗格、不修改业务状态，不属于业务命令 |

静态复核重点：业务 `Click`/双击处理器只构造命令文本并调用 `CommandBus`；不得直接调用日志过滤服务、停靠服务、
剪贴板或文件选择服务。命令处理器可以持有这些系统交互，以保证手输、脚本、模块和 MCP 使用同一描述符与回执。
主窗口/独立浮窗的原生移动属于窗口宿主交互；浮窗拖动过程中为保持鼠标锚点而执行的几何恢复不另建命令，
但离散的最大化/还原必须使用 `win.float-state`，且不得改变 AppShell 停靠模型。
普通真实页签拖出沿用 AvalonDock 原生停靠流程；专注真实页签改变布局时必须依次执行现有 `win.restore` 与 `win.float`。
空白顶栏不得推断停靠目标或触发页面拖出。
