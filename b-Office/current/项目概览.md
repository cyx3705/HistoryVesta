# AppShell 项目概览

更新日期：2026-07-30

## 一句话定义

AppShell 是供 OneHistory 桌面应用和服务宿主固定版本消费的通用 .NET 8/WPF 壳框架，统一提供
命令、停靠布局、日志、设置、资源、面板、模块、MCP/Web 接入与服务生命周期能力。

## 目标与边界

### 目标

- 以固定 NuGet 包提供稳定、可测试、可回滚的公共合同，不再复制源码作为应用底座。
- 以单一窗口模型承载中央主工作区和四边工具页，并保留布局持久化与模块生命周期。
- 以默认最小能力、安全边界、公开 API 基线和自动化门禁守住 3.0.3 冻结契约。
- 让消费方和 AI 从稳定入口定位当前包、API、命令和限制，无需扫描历史归档。

### 范围

- `AppShell.Core`、`Services`、`Shell`、`ServiceHost` 四个公共包。
- AppShell 演示宿主、框架测试、隔离包消费测试和示例模块。
- 消费合同编辑源、候选打包、正式归档及 Z 级当前消费快照。

### 非目标

- 不承载 OHS、WBall 或其他消费应用的业务功能和数据模型。
- 不提供已在 3.0 删除的数据库服务、通用表窗口或 `db.*` 命令。
- CI 不自动发布包、更新正式快照、创建标签或部署消费方。
- 3.0.x 不新增公开 API 或一般性功能；后续演进进入新版本线。

## 关键约束

- 平台：Windows、WPF、`net8.0` / `net8.0-windows`、win-x64 演示宿主。
- 工具链：根 `global.json` 固定 .NET SDK `9.0.315`；C# 检出行尾固定为 CRLF。
- 兼容性：消费方精确固定 3.0.3；公开面以四份 `PublicAPI.Shipped.txt` 为基线。
- 默认能力：`EnableMcp=false`、`EnableModules=false`，消费方按需显式启用。
- 安全：MCP 暴露需要描述符显式允许；敏感值不得进入日志、历史或未授权响应。
- 发布：正式发布脚本只在人工批准、来源洁净时执行，且不自动推送 NuGet.org。
