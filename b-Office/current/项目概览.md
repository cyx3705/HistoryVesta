# OneHistoryStudio 项目概览

更新日期：2026-08-07

## 一句话定义

OneHistoryStudio 是运行在 AppShell 中的自用项目与 Git 治理模块，统一管理编号项目、分支继承、Meta 文件、Git 文件规则、提交、推送和分支历史。

## 目标与边界

### 目标

- 以单个 AppShell 模块提供五个业务页面和稳定命令集合。
- 保留原有项目库与 Git 数据，移除独立 OHS 进程和第二套宿主运行时。
- 通过两层发布区交付可校验、可回滚的正式模块快照。

### 范围

- `b-Code-Studio/Module` 的模块入口，以及其链接使用的项目、Git、视图和业务组合源码。
- `b-Code-Verify` 的 Contracts、功能 Smoke、模块装载和发布门禁。
- `b-Publish` 的单槽候选、正式历史包和事务目录。
- `z-Package-OneHistoryStudio` 的最新正式消费快照。

### 非目标

- 不提供独立 `OneHistoryStudio.exe`、独立 ServiceHost、独立 Shell、Web/MCP 网关或开机自启动项。
- 不复制或发布 AppShell 运行库；宿主从 `2026-023-AppShell/z-Package-AppShell` 独立交付。
- 不把 OHS CLR 类型作为跨模块二进制 API；其他模块通过宿主命令总线协作。

## 关键约束

- 平台：Windows、.NET 8 WPF、AppShell 3.1.8 current-host 宿主合同；AppShell 是否洁净以其 z 快照 manifest 为准。
- 兼容性：模块名 `OneHistoryStudio`、五个窗口 ID 和现有业务命令名保持稳定。
- 数据：模块数据根由 AppShell `IModuleContext.DataDirectory` 提供，并在其下使用 `OneHistoryStudio` 子目录。
- 安全：MCP 只投影只读命令；写操作仍由宿主确认策略控制。
- 发布：不执行开机自启动测试，不从 OHS 包发布或启动宿主进程。
