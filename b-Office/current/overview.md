# MyAPI V4 项目概览

更新日期：2026-08-05

## 一句话定义

MyAPI V4 是 OneHistory 的后端模块运行时探索：负责模块发现、命令注册、命令管线和对外调用适配；页面由独立前端模块提供，AppShell 与 Web 只承担页面之间的宿主层。

## 当前状态

| 状态 | 内容 |
| --- | --- |
| exploration | 从 Lite 原型演进 V4 后端内核，不承诺稳定 API |
| 已完成 | 旧 Core 删除；命令合同、运行时和宿主完成拆分；测试模块外置为独立 b-Code |
| 当前基线 | `b-Code-MyAPI/MyAPI.sln`，目标框架 net8.0 |
| 已验证 | 8 项契约测试、Release 构建、真实 DLL 加载和 HTTP 命令调用 |
| 尚未承诺 | 权限模型、审计存储、跨进程协议、正式发布包 |

## 与 AppShell 3.0 的关系

`2026-023-AppShell` 的 3.0.3 冻结实现不受本探索影响。V4 只在本仓库演进，验证通过后也必须经过独立设计和消费评审，不能直接替换 3.0 包。
