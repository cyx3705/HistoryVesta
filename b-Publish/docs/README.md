# OneHistoryStudio 文档中心

> 当前版本：V2.4.1
> 更新日期：2026-07-25
> 本文件位置：`b-Office\OHS\meta\README.md`

本页是 OneHistoryStudio 的唯一现行文档入口。编号文档保留实施和验收历史；日常使用优先查看下列现行手册。

## 文档目录结构（V2.4.1）

OHS 文档统一上抛到伞形项目的 `b-Office/OHS`，不再属于代码组件：

| 目录 | 内容 | 数量 |
|---|---|---|
| `versions\` | 版本工程文档 `00` ~ `27`，按序记录每个版本的实施方案与验收 | 28 |
| `meta\` | OHS 现行手册、规划与清单（本目录） | 8 |
| `snapshots\` | 各版本的行为基线快照（`command-manual.md` + `console-baseline.log`） | 7 组 |

**旧路径映射**（历史交付记录中出现的 `docs\…` 按此解析）：

| 文档里写的旧路径 | 现位置 |
|---|---|
| `docs\00-…` ~ `docs\25-…` | `versions\` 下同名文件 |
| `docs\snapshots\vNNN\` | `snapshots\vNNN\` |
| `docs\命令手册.md`、`docs\README.md` 等其余 `.md` | `meta\` 下同名文件 |

> **历史文档不改写**：`02-项目验收单`、各版本交付记录里的 `docs\…` 路径是当时的事实，
> 保留原样；需要定位时查上表。只有导航链接（本页与《发布与升级》）已更新为可用路径。

> **随程序发布的 Help 不受影响**：`b-Code-Studio/Studio.csproj` 用 `Link="docs\…"` 固定发布布局，
> 部署目录下仍是 `docs\*.md` 六份手册——那是面向使用者的产品界面，不随源码目录调整而变。
