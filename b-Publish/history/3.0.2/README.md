# AppShell 3.0.2 formal history snapshot

This directory is the minimal formal snapshot migrated from the legacy release archive.
It is not the current consumer entry point; use the repository-level z-Package-AppShell.

- feed/: runtime .nupkg files actually published for this version.
- docs/: consumer contracts when that version had versioned documents.
- AppShell.reuse.md: compact reuse entry when available for that version.
- manifest.json and SHA256SUMS: snapshot identity and complete file checksums.
