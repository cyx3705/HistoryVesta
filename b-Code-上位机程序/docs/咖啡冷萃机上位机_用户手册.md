# 咖啡冷萃机上位机用户手册

版本：0.4.0-M4  
适用对象：冷萃机调试、生产测试和日常操作人员

## 1. 启动与界面

启动 `AppShell.exe` 后，主画面显示上舱体、下舱体、电气仓和流向状态。右侧“手动控制 / GPIO”窗口用于连接 ESP32、手动上液/降液/停止、启动固定循环、保存配方和查看最近记录。

程序启动时不会自动开启任何输出。GPIO15、GPIO16 默认关闭；即使上次异常退出，重新打开后也需要人工重新连接设备并发出动作命令。

## 2. 设备连接

1. 将 ESP32 通过 USB 连接到电脑。
2. 在“设备连接”区域点击“刷新”，选择对应 COM 口。
3. 点击“连接”。
4. 连接成功后，界面状态应显示“设备 | 在线 COMx”，控制台会出现 `device.tx`、`device.rx` 日志。

正常心跳示例：

```text
[device.tx] {"id":1,"cmd":"ping"}
[device.rx] {"type":"pong","id":1}
[device.rx] {"type":"state","seq":2,"mode":"idle","gpio15":false,"gpio16":false}
```

点击“断开”后，上位机回到模拟模式，设备输出不再由上位机接管。

## 3. 手动控制

“上液”会请求 GPIO15 有效，方向为“下舱体 -> 上舱体”。  
“降液”会请求 GPIO16 有效，方向为“上舱体 -> 下舱体”。  
“停止”会关闭 GPIO15/GPIO16。

设备模式下，按钮不会直接假定动作成功；上位机会先发送命令，等待 ESP32 回传确认和状态快照。按“上液”后应看到：

```text
[device.tx] {"id":...,"cmd":"set","mode":"up"}
[device.rx] {"type":"ack","id":...,"cmd":"set","ok":true}
[device.rx] {"type":"state","mode":"up","gpio15":true,"gpio16":false}
```

如果只看到 `state idle`，说明设备没有进入上液状态；优先检查是否运行了最新上位机、固件是否烧录正确、串口是否被其他软件占用。

## 4. 固定循环

固定循环由 5 个参数组成：

- 上液秒数
- 上液停留
- 降液秒数
- 降液停留
- 循环次数

点击“启动循环”后，程序按“上液 -> 停留 -> 降液 -> 停留”的顺序执行。运行中参数会锁定，避免中途改动导致步骤不一致。

可用操作：

- “暂停”：关闭输出并冻结计时。
- “继续”：从暂停的阶段继续。
- “终止”：关闭输出，记录终止原因，回到待机。

设备模式下启动固定循环前必须保持 ESP32 在线；运行中如果串口超时或断开，编排会自动终止并关闭输出。

## 5. 命名配方

M4 支持保存和载入命名配方。首次启动会自动创建：

- 默认冷萃：30s / 5s / 30s / 5s / 3 次
- 快速联调：3s / 1s / 3s / 1s / 1 次

保存配方：

1. 填写固定循环参数。
2. 在配方名称框输入名称。
3. 点击“保存”。

载入配方：

1. 在配方下拉框选择配方。
2. 点击“载入”。
3. 参数会写回固定循环输入框。

删除配方：

1. 选择要删除的配方。
2. 点击“删除”。

配方与历史数据保存在：

```text
%AppData%\ColdBrewMachine\data\brew-m4.json
```

## 6. 最近记录

“最近记录”区域显示运行记录、GPIO 事件、设备快照变化和故障记录。程序最多在文件中保留 500 条历史，界面显示最近 80 条。

典型记录包括：

- 固定循环启动/完成/终止
- 手动上液/降液/停止
- 设备快照从 idle 变为 up/down
- GPIO15/GPIO16 同时有效的互锁故障

## 7. 控制台指令

常用指令：

```text
device.list
device.connect port=COM4
device.disconnect
device.state
device.mode enabled=true

brew.up
brew.down
brew.stop
brew.run up=30 upHold=5 down=30 downHold=5 cycles=3
brew.pause
brew.resume
brew.abort
brew.history limit=20

recipe.list
recipe.save name=浅烘测试 up=30 upHold=5 down=30 downHold=5 cycles=3
recipe.load name=浅烘测试
recipe.run name=浅烘测试
recipe.delete name=浅烘测试
```

## 8. 故障处理

无法连接串口：

- 确认 ESP32 已插入电脑。
- 点击“刷新”重新枚举串口。
- 关闭串口监视器、PlatformIO Monitor、Arduino Serial Monitor 等占用 COM 口的软件。
- 重新插拔 USB 后再连接。

按钮点击后设备不动作：

- 看控制台是否有 `device.tx {"cmd":"set","mode":"up"}`。
- 如果没有，说明上位机没有进入设备模式或不是最新版本。
- 如果有 `device.tx` 但没有 `ack`，检查串口线和固件协议。
- 如果回传 `gpio15:true` 但继电器/灯不亮，检查 GPIO15 接线、继电器有效电平和驱动电路。

出现互锁故障：

- 上位机会立即关闭 GPIO15/GPIO16，并进入故障显示。
- 检查固件是否错误地同时拉高两路输出。
- 检查外部驱动电路是否短接或反馈异常。
- 故障排除后重新点击“停止”或重连设备。

运行中断：

- 如果是设备模式，检查心跳是否超时。
- 如果用户点击“终止”或“停止”，历史记录会写明原因。
- 重新启动循环前确认液路和舱体状态安全。

## 9. 日常验收

每次更换固件或接线后，建议按以下顺序验收：

1. 连接 ESP32，确认心跳和 `state idle` 正常。
2. 点击“上液”，确认只有 GPIO15 有效。
3. 点击“停止”，确认 GPIO15/GPIO16 全部关闭。
4. 点击“降液”，确认只有 GPIO16 有效。
5. 运行“快速联调”配方，确认步骤、进度和最近记录完整。
6. 拔掉 USB 或复位 ESP32，确认上位机能显示断开、超时或重新握手，不误报成功。
