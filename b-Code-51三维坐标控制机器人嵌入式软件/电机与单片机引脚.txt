# STC8A8K64S4A12 电机脉冲 / 方向控制引脚说明

文档核心原理图（图 24）明确：**P0 口（P0.0~P0.5）输出三轴步进电机 PUL 脉冲、DIR 方向信号**，对应 CON2 插座 Q0~Q5 引脚，定义如下：

1. **脉冲波形（CLK/PUL，控制步数、运动波形）**
   - P0.0 → Q0：X 轴脉冲 CLKx
   - P0.2 → Q2：Y 轴脉冲 CLKy
   - P0.4 → Q4：Z 轴脉冲 CLKz
   作用：每输出 1 个脉冲方波，步进电机走 1 细分步；脉冲频率决定运行速度，脉冲总数决定移动距离，是电机运动的波形驱动信号。
2. **方向电平（DIR，控制正反转）**
   - P0.1 → Q1：X 轴方向 DIRx
   - P0.3 → Q3：Y 轴方向 DIRy
   - P0.5 → Q5：Z 轴方向 DIRz
   作用：高低电平切换电机旋转方向，**无波形，仅稳定高低电平**，脉冲输出前先置 DIR 电平，确定运动正负向。
